## 1. Web UI 실행

```sh
npx @deepseek-ai/dsh web
```

브라우저가 열리지 않으면 `http://127.0.0.1:3080`으로 이동하세요.

## 2. 모델 연결

**Settings → Models**에서 공급자, 모델 이름, API 키를 입력하고 저장합니다. 다음 요청부터 적용되며 다시 시작할 필요가 없습니다. OpenAI 호환 엔드포인트는 base URL과 모델 식별자를 정확히 확인하세요.

## 3. 작업 공간 선택

**Choose workspace**에서 검사할 저장소를 선택합니다. 작업 공간은 신뢰 경계입니다. 관련 없는 비밀이나 개인 파일이 든 상위 디렉터리는 열지 마세요.

## 4. 첫 작업 실행

```text
Summarize this repository and identify its main packages.
```

응답에 언급된 파일이 실제로 있는지 확인한 뒤 작은 테스트 하나를 실행해 보세요. 권한 요청과 최종 diff를 각각 검토합니다. `workspace-write`는 쓰기를 제어하지만 모든 읽기, 프로세스, 네트워크 동작을 격리하지는 않습니다.
