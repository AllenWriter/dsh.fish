---
title: 제출과 소유권 신청
description: 실제 소스를 dsh.fish에 제출하고 manifest 재검사와 GitHub 소유권 확인을 받습니다.
---

[제출 폼](/submit)은 `npm:<package>` 또는 `github:<owner>/<repo>[/<path>]`와 예상 종류를 받습니다. 카탈로그는 실제 manifest를 다시 읽습니다. `kindHint`는 검사 순서만 바꾸며 증거를 대신하지 않습니다.

제출에는 브라우저 세션이 필요합니다. 소스를 읽을 수 있고 현재 OAuth GitHub 계정이 저장소 소유권을 증명하면 즉시 승인되며, 그 밖의 경우 검토 대기열로 갑니다. 기기 토큰은 검색, 설치, 평가에는 쓸 수 있지만 게시나 소유권 신청에는 쓸 수 없습니다.

README가 바뀌면 현지화를 다시 생성합니다. 소스 hash가 일치하지 않으면 오래된 번역 대신 원문 README를 표시합니다.
