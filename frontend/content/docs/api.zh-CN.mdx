---
title: REST API
description: 使用公开 JSON API 搜索 dsh.fish、检查制品与安装计划、读取评分并同步目录。
---

公开 API 用于发现和只读目录集成。完整结构请查看 [OpenAPI 文档](/openapi.json)。

```sh
curl -s 'https://dsh.fish/api/v1/artifacts?q=postgres&kind=mcp-server'
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID'
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/install-plan?profile=web'
```

安装计划是数据，不应盲目执行。向用户展示每个文件、包和 profile patch；需要构建脚本时单独确认。

```sh
curl -s 'https://dsh.fish/api/v1/scoring'
curl -s 'https://dsh.fish/api/v1/catalog/version'
curl -s 'https://dsh.fish/api/v1/catalog/snapshot' -o catalog.json
```

先轮询轻量 version 端点，只在 `dataVersion` 变化时下载新 snapshot，并保存 `ETag`。公开读取无需账户；认证写操作和 scope 以 OpenAPI 为准。
