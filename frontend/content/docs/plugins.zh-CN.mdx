DeepSeek Harness 运行在 Cordis 插件框架之上。模型适配器、工具注册表、会话日志和智能体循环都是从配置挂载的插件。

没有需要打补丁的特权内核：要扩展 Harness，就把一个插件挂载到其他插件旁边。插件注册的一切都会在卸载时被清理。

内核因此保持小巧。想要新能力时，你安装一个插件，而不是等待 Harness 升级。

## 插件可以是什么

dsh.fish 目录收录四种构件类型，各有自己的清单契约：

- [Bundle](/docs/publish/bundle)：向配置档案添加一层插件 patch 的 npm 包。
- [Skill](/docs/publish/skill)：智能体按需加载的 Markdown 指令文件。
- [Agent preset](/docs/publish/agent-preset)：一个 `agent.cordis.yml`，让某个会话拥有自己的工具和提示词。
- [Profile](/docs/publish/profile)：构成完整组合的有序 bundle 栈。

## 信任问题

插件是以你授予 Harness 的权限运行的代码。

它在你的工作区内行动。git 安装还可能在智能体沙箱之外运行包的构建脚本。

README 告诉你的是作者的声明，不是安装实际会做什么。

dsh.fish 正是为这一缺口而存在。

目录读取每个来源真实的清单和文件。每个构件页面都在你运行任何命令之前展示安装计划（安装将执行的文件写入和包安装）。

先检查，再安装。

要自己编写插件，从[开发第一个插件](/docs/develop/first-plugin)开始。
