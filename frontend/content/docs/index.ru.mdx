DeepSeek Harness — открытая среда выполнения агентов. dsh.fish — независимый каталог расширений, которые Harness умеет загружать: здесь их можно найти, проверить и установить.

## Выберите маршрут

- **Первый запуск:** [краткое руководство](/docs/quickstart) проведёт через Web UI, модель, рабочую папку и первую задачу.
- **Новая возможность:** используйте [плагин Hub](/docs/hub) в сеансе или [dsh.fish CLI](/docs/cli) в терминале. До установки проверьте план.
- **Разработка интеграции:** создайте [первый плагин](/docs/develop/first-plugin), добавьте [инструмент](/docs/develop/tool) и [проверяемую конфигурацию](/docs/develop/configuration).
- **Публикация:** выберите [формат](/docs/publish/bundle), отправьте исходник и проверьте публичную оценку.

dsh.fish читает настоящий manifest репозитория или пакета. Сайт, CLI и плагин Hub используют единый API плана установки. Скрипты сборки Git-пакетов выполняются вне песочницы агента, поэтому требуют отдельного явного разрешения.

Harness пока находится в developer preview. Версионные детали смотрите в [официальном руководстве](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart).
