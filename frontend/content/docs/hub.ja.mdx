title: Hub プラグイン

---

Hub プラグイン（`@dsh-fish/hub`）は dsh.fish のカタログを実行中のセッションに持ち込みます。エージェントはアーティファクトを検索し、インストールで何が実行されるかを見せ、あなたが同意してからインストールします。セッションを離れる必要はありません。

## プラグインを追加する

```sh
dsh plugin --profile <profile> add @dsh-fish/hub
```

`<profile>` はハーネスが起動するプロファイルです。標準のランチャーなら `web`、デスクトップ版ならそれが起動するプロファイルになります。npm で公開されるパッケージには `lib/` がビルド済みで含まれているため、このインストールはビルドスクリプトを実行せず、`allowBuilds` の指定も不要です。

### Local DSH

[Local DSH](https://github.com/stvlynn/local-dsh) は `local-dsh` で起動し、そのランチャーはグローバルな `PATH` ではなくアプリ同梱のランタイム内にあります。アプリが実際に起動するプロファイルへ入れるため、そのランチャーを使ってください。

```sh
APP_DATA="$HOME/Library/Application Support/com.localdsh.app"
RUNTIME="$(find "$APP_DATA/runtime" -maxdepth 1 -type d ! -name runtime ! -name '.partial-*' | head -n 1)"
export PATH="$RUNTIME/bin:$PATH"

dsh plugin --profile local-dsh add @dsh-fish/hub
```

その後 DSH を再起動します。プラグインのツールは起動時に読み込まれます。アプリは起動ごとに管理対象のバンドル一覧を書き直しますが、あなたが追加したバンドルは保持するため、再起動後もプラグインは残ります。

### git からインストールする

git からのインストールは開発時のフォールバックで、サブディレクトリを指定する必要があります。リポジトリのルートは private な workspace であり、このプラグインではありません。

```sh
dsh plugin --profile <profile> add github:stvlynn/dsh.fish#path:packages/dsh-plugin-hub
```

このチェックアウトには `lib/` がないためインストール時にビルドが走り、pnpm 10 以降は許可するまでビルドスクリプトを拒否します。pnpm が表示するパッケージキーをプロファイルの `pnpm-workspace.yaml` にコピーし、`add` をもう一度実行してください。この許可は、パッケージ自身のコードをインストール時にエージェントのサンドボックス外で実行するものです。後の push で実行内容が変わらないよう、commit を固定してください。

### `dsh-hub` からの移行

以前のバージョンは `dsh-hub` という名前でリポジトリのルートからインストールしていました。

```sh
dsh plugin --profile <profile> remove dsh-hub
dsh plugin --profile <profile> add @dsh-fish/hub
```

`$DSH_HOME/.dsh-fish-lock.json` に記録済みのインストールは改名の影響を受けません。

## インストール

`hub_install` はこのマシンでインストールプランを実行します。

- skill と preset のファイルを書き込みます
- バンドルにはパッケージマネージャーを実行します

終わったらハーネスを再起動すると、新しい行が読み込まれます。

ソースからビルドするパッケージを含むプランは、呼び出し側が `allowBuildScripts: true` を渡すまで `hub_install` が拒否します。その手順はパッケージのコードをインストール時にこのマシン上、エージェントのサンドボックス外で実行するため、エージェントはあなたに確認しに戻る必要があります。自分で許可することはできません。

成功したインストールは `$DSH_HOME/.dsh-fish-lock.json` に記録されます。

- `hub_list` はこのマシンがインストールしたものを表示します
- `hub_update` はインストール済みアーティファクトの現在のプランを再実行します
- `hub_remove` は記録されたインストール（ファイル、パッチ行、パッケージ）を取り消します

このロックファイルは `@dsh-fish/cli` と共有されるので、[CLI](/docs/cli) からも同じインストールが見えます。

## サインイン

サインインするとインストールがあなたのアカウントに紐付き、`hub_rate` が使えます。カタログの閲覧にアカウントは要りません。

`hub_account` に `action: "login"` を渡すと OAuth デバイスフローが始まります。

- ツールが短いコードと URL を返します
- ブラウザで URL を開いて承認してください
- プラグインは承認されるまでポーリングします

エージェントが代わりに承認することはできません。

トークンは `$DSH_HOME/.dsh-fish-token.json` にパーミッション 0600 で書き込まれ、ログには出ません。

このトークンは意図的にブラウザセッションより弱くなっています。あなたとしてカタログの閲覧、インストールプランの解決、アーティファクトの評価はできますが、公開や所有権の申請はできません。

## 設定画面のセクション

ブラウザークライアントを提供するハーネスでは、このプラグインは設定画面に **dsh.fish** セクションを追加し、3 つのタブを持ちます。

- **Browse**：カタログを検索し、何かを実行する前にアーティファクトのインストールプランを表示します。ソースからビルドするパッケージは、そのことを明記したボタンを押すまで拒否されます。
- **Installed**：このプロファイルがハブ経由でインストールしたものを一覧し、そこから削除もできます。
- **Account**：同じデバイスフローでサインインし、コードと検証 URL を通常のリンクとして表示します。

これは同じインストーラーに対する 2 つ目の画面であり、2 つ目のインストーラーではありません。このセクションが呼ぶ同一オリジンのルートは `hub_*` ツールと同じコードを実行し、書き込み先も同じ `$DSH_HOME/.dsh-fish-lock.json` です。したがって Installed の一覧は `hub_list` の報告と完全に一致します。

アカウントに関わるものはブラウザーに渡りません。デバイスコードと保存されたトークンはホスト側に留まります。だからこそデスクトップアプリは、検証リンクをアプリのウィンドウ内ではなくシステムブラウザーに渡せます。

ブラウザークライアントを提供しないプロファイルでも、ツールは読み込まれます。

## 安全性

ファイル書き込みは解決された `$DSH_HOME` の内側に制限され、外へ出ようとするプランは拒否されます。

ソースからのビルドには上記のとおり明示的な同意が必要です。

`hub_rate` には独自のルールがあります。エージェントはこのマシンで実際にインストールして使ったものだけを、直接の根拠に基づいて評価し、評価するときはあなたに伝えます。

## ツール

| ツール        | 機能                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| `hub_search`  | テキストとアーティファクトの種類でレジストリを検索します。               |
| `hub_show`    | 1 件のアーティファクトの詳細と、インストールが実行する内容を表示します。 |
| `hub_install` | このマシンでインストールプランを実行します。                             |
| `hub_list`    | このマシンが hub 経由でインストールしたアーティファクトを一覧します。    |
| `hub_remove`  | 記録されたインストール（ファイル、パッチ行、パッケージ）を取り消します。 |
| `hub_update`  | インストール済みアーティファクトの現在のプランを再実行します。           |
| `hub_account` | OAuth デバイスフローでサインイン、状態確認、サインアウトを行います。     |
| `hub_reviews` | コミュニティの評価。サイトの 1〜5 つ星、平均、分布、コメント。           |
| `hub_rate`    | インストール済みアーティファクトを 1〜5 つ星で評価。公開コメント可。     |

## 設定

```yaml
- id: hub
  name: '@dsh-fish/hub'
  config:
    baseUrl: https://dsh.fish # セルフホストの場合はここだけ変えます
    targetProfile: current # または具体的なプロファイル名
```
