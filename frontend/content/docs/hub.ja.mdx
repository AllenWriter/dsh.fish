title: Hub プラグイン

---

Hub プラグイン（`dsh-hub`）は dsh.fish のカタログを実行中のセッションに持ち込みます。エージェントはアーティファクトを検索し、インストールで何が実行されるかを見せ、あなたが同意してからインストールします。セッションを離れる必要はありません。

## プラグインを追加する

```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

このパッケージは TypeScript なので、git からのインストールでは `lib/` をビルドする `prepare` スクリプトが動きます。pnpm 10 以降は許可するまでこれを拒否します。pnpm が表示するパッケージキーをプロファイルの `pnpm-workspace.yaml` にコピーしてください。

```yaml
allowBuilds:
  dsh-hub: true
```

その後 `add` をもう一度実行します。

この許可は、パッケージ自身のコードをインストール時にエージェントのサンドボックス外で実行するものです。後の push で実行内容が変わらないよう、commit を固定してください。

## 探す

`hub_search` はフリーテキストでカタログを検索します。`kind` 引数でアーティファクトの種類を一つに絞れます。返される id は他の hub ツールに渡せます。

カタログの閲覧にアカウントは要りません。

## 確認する

`hub_show` は 1 件のアーティファクトの詳細を表示し、このマシンでインストールが実行するコマンドを正確に示します。`hub_reviews` はコミュニティの評価を匿名で読み取ります。1〜5 つ星の平均、分布、最近のコメントです。

インストールさせる前にこの両方を確認してください。同じ根拠はウェブサイトにもあるので、そちらで確かめても構いません。

## インストール

`hub_install` はこのマシンでインストールプランを実行します。

- skill と preset のファイルを書き込みます
- MCP と hook の行をプロファイルのパッチレイヤーに追加します
- バンドルにはパッケージマネージャーを実行します

終わったらハーネスを再起動すると、新しい行が読み込まれます。

ソースからビルドするパッケージを含むプランは、呼び出し側が `allowBuildScripts: true` を渡すまで `hub_install` が拒否します。その手順はパッケージのコードをインストール時にこのマシン上、エージェントのサンドボックス外で実行するため、エージェントはあなたに確認しに戻る必要があります。自分で許可することはできません。

成功したインストールは `$DSH_HOME/.dsh-fish-lock.json` に記録されます。

- `hub_list` はこのマシンがインストールしたものを表示します
- `hub_update` はインストール済みアーティファクトの現在のプランを再実行します
- `hub_remove` は記録されたインストール（ファイル、パッチ行、パッケージ）を取り消します

このロックファイルは `@dsh-fish/cli` と共有されるので、[CLI](/docs/cli) からも同じインストールが見えます。

## サインイン

サインインするとインストールがあなたのアカウントに紐付き、`hub_rate` が使えます。カタログの閲覧にアカウントは要りません。

`hub_account` に `action: "login"` を渡すと OAuth デバイスフローが始まります。

- ツールが短いコードと URL を返します
- ブラウザで URL を開いて承認してください
- プラグインは承認されるまでポーリングします

エージェントが代わりに承認することはできません。

トークンは `$DSH_HOME/.dsh-fish-token.json` にパーミッション 0600 で書き込まれ、ログには出ません。

このトークンは意図的にブラウザセッションより弱くなっています。あなたとしてカタログの閲覧、インストールプランの解決、アーティファクトの評価はできますが、公開や所有権の申請はできません。

## 安全性

ファイル書き込みは解決された `$DSH_HOME` の内側に制限され、外へ出ようとするプランは拒否されます。

ソースからのビルドには上記のとおり明示的な同意が必要です。

`hub_rate` には独自のルールがあります。エージェントはこのマシンで実際にインストールして使ったものだけを、直接の根拠に基づいて評価し、評価するときはあなたに伝えます。

## ツール

| ツール        | 機能                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| `hub_search`  | テキストとアーティファクトの種類でレジストリを検索します。               |
| `hub_show`    | 1 件のアーティファクトの詳細と、インストールが実行する内容を表示します。 |
| `hub_install` | このマシンでインストールプランを実行します。                             |
| `hub_list`    | このマシンが hub 経由でインストールしたアーティファクトを一覧します。    |
| `hub_remove`  | 記録されたインストール（ファイル、パッチ行、パッケージ）を取り消します。 |
| `hub_update`  | インストール済みアーティファクトの現在のプランを再実行します。           |
| `hub_account` | OAuth デバイスフローでサインイン、状態確認、サインアウトを行います。     |
| `hub_reviews` | コミュニティの評価。サイトの 1〜5 つ星、平均、分布、コメント。           |
| `hub_rate`    | インストール済みアーティファクトを 1〜5 つ星で評価。公開コメント可。     |

## 設定

```yaml
- id: hub
  name: dsh-hub
  config:
    baseUrl: https://dsh.fish # セルフホストの場合はここだけ変えます
    targetProfile: current # または具体的なプロファイル名
```
