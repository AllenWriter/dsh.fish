---
title: 送信と所有権の申請
description: 実際のソースを dsh.fish に送り、manifest の再検査と GitHub 所有権の確認を受けます。
---

[送信フォーム](/submit)は `npm:<package>` または `github:<owner>/<repo>[/<path>]` と想定種類を受け取ります。カタログは実際の manifest を読み直します。`kindHint` は検査順を変えるだけで、証拠にはなりません。

送信にはブラウザセッションが必要です。ソースを読めて、現在の OAuth GitHub アカウントが所有権を証明できれば即時承認され、それ以外は審査されます。デバイストークンは検索、導入、評価には使えますが、公開や所有権申請には使えません。

README が変わるとローカライズを再生成します。ソース hash が一致しない場合は古い翻訳ではなく元の README を表示します。
