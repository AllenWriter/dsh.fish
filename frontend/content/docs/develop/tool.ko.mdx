title: 도구 등록
description: DeepSeek Harness 플러그인에 타입이 있는 도구를 추가하고 입력, 결과, 정리를 검증합니다.
---

도구 하나에는 분명한 결과 하나만 두고, 모든 입력을 검증하며, 확인 가능한 근거를 반환하고 숨은 부작용을 피하세요.

```ts
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(
    defineTool({
      name: 'greet',
      description: 'Greet someone by name.',
      parameters: {
        name: {
          type: 'string',
          required: true,
          description: 'The name to greet',
        },
      },
      output: {
        schema: { type: 'string' },
        render: (_args, value) => [{ type: 'text', text: value }],
      },
      async execute(args) {
        return `Hello, ${args.name}!`
      },
    }),
  )
}
```

현재 공식 API에 따라 `apply(ctx)` 안에서 등록해 플러그인을 언로드할 때 도구도 제거되게 합니다. 정상, 빈 값, 잘못된 입력을 테스트하고 Web UI에서 `Use greet for Ada.`를 보내 도구 행의 IN/OUT을 확인하세요.

API 키를 인수나 결과에 넣지 말고 Harness 자격 증명 기능에서 읽으며 로그에서는 가리세요.
