---
title: プラグインを設定、梱包、導入する
description: 設定の検証、profile の上書き順序、ビルド成果物の安全な導入と削除を確認します。
---

無効な設定は明確なエラーにし、暗黙の既定値で問題を隠さないでください。

構成順序は profile bundles → profile `cordis.patch` → home `cordis.patch` → CLI patch です。後の層は一致した行全体を置換し、deep merge はしません。

```sh
dsh --profile demo --dump-config
pnpm pack
dsh plugin --profile demo add ./hello-harness-0.1.0.tgz
```

公開物には実行時に必要な `lib/`、manifest、README、license を含め、作業ツリーではなく実際の tarball をテストします。Git の `prepare` はサンドボックス外で動くため、再現可能にし、commit の固定を推奨します。削除後にツール、ファイル、バックグラウンド資源が残らないことも確認します。
