현재 공식 개발 흐름은 DeepSeek Harness 소스 checkout에서 실행합니다. 공식 소스 실행 절차를 마친 뒤 저장소 루트에 `scratch-plugin/src/my-plugin.ts`를 만드세요.

```ts
import type { Context } from '@deepseek-ai/cordis'
export const name = 'hello-harness'
export function apply(ctx: Context): void {
  console.log('[hello-harness] plugin loaded!')
}
```

절대 경로를 사용하는 `scratch-plugin/cordis.yml`을 만듭니다.

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

`http://127.0.0.1:3080`을 열고 터미널의 로드 메시지를 확인하세요. `ctx`를 통한 등록은 언로드할 때 자동으로 정리됩니다. 타이머나 연결은 disposer를 반환하는 `ctx.effect()`를 사용합니다.
