当前官方开发流程从 DeepSeek Harness 源码仓库运行。先完成官方的源码启动步骤，再在仓库根目录创建 `scratch-plugin/src/my-plugin.ts`：

```ts
import type { Context } from '@deepseek-ai/cordis'

export const name = 'hello-harness'

export function apply(ctx: Context): void {
  console.log('[hello-harness] plugin loaded!')
}
```

创建 `scratch-plugin/cordis.yml`，并把路径替换为源码仓库的绝对路径：

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

打开 `http://127.0.0.1:3080`，确认终端输出加载信息。通过 `ctx` 注册的能力会在卸载时自动清理；计时器或网络连接等外部资源应使用 `ctx.effect()` 返回 disposer。
