---
title: 开发第一个插件
description: 创建一个最小的 DeepSeek Harness 插件，用源码 overlay 加载，并在 Web UI 中观察它的运行。
---

DeepSeek Harness 由插件组合而成。插件是一个导出 `apply` 函数的 TypeScript 模块。harness 加载插件时会调用 `apply`，并传入一个 Cordis context，插件注册的一切都经过这个对象。

本教程会做一个最小的插件，把它加载进 Web UI，再把它移除。流程在 DeepSeek Harness 源码仓库中运行，请先完成官方的源码启动步骤。

## 创建插件

在仓库根目录创建一个临时目录：

```sh
mkdir -p scratch-plugin/src
```

创建 `scratch-plugin/src/my-plugin.ts`：

```ts
import type { Context } from '@deepseek-ai/cordis'

export const name = 'hello-plugin'

export function apply(ctx: Context): void {
  console.log('[hello-plugin] plugin loaded!')
}
```

通过 `ctx` 注册的内容都是 effect：插件卸载时 harness 会自动撤销，不会在两次加载之间留下残留。

## 用源码 overlay 加载

源码 overlay 是一个 patch 文件，把插件插入组合后的配置，而不改动配置档案本身。

运行 `pwd`，然后创建 `scratch-plugin/cordis.yml`，把示例路径替换为源码仓库的绝对路径：

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

路径必须是绝对路径。patch 只提供配置，不改变加载器解析模块的目录。

用 overlay 启动 Web UI：

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

## 在 Web UI 中验证

打开 `http://127.0.0.1:3080`。启动过程中终端会打印 `[hello-plugin] plugin loaded!`。发送一条消息并观察这次运行：Web UI 会列出每个步骤，包括模型的 Think 行和每次工具调用的输入与输出。

## 迭代与移除

修改插件、保存、再看结果。对配置档案级和 home 级 `cordis.patch.yml` 文件的修改会热重载；添加、移除或重新构建已安装的包（bundle）则需要重启。

对于 context 不管的资源，比如计时器或网络连接，在 `ctx.effect()` 里获取它并返回一个 disposer。插件卸载时 harness 会运行这个 disposer。

要移除插件，停掉命令，不带 `--patch` 重启即可。它的注册会随之消失。
