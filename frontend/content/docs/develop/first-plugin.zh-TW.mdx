目前官方開發流程從 DeepSeek Harness 原始碼倉庫執行。先完成官方的原始碼啟動步驟，再於倉庫根目錄建立 `scratch-plugin/src/my-plugin.ts`：

```ts
import type { Context } from '@deepseek-ai/cordis'
export const name = 'hello-harness'
export function apply(ctx: Context): void {
  console.log('[hello-harness] plugin loaded!')
}
```

建立 `scratch-plugin/cordis.yml`，並將路徑替換為原始碼倉庫的絕對路徑：

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

開啟 `http://127.0.0.1:3080` 並確認終端輸出載入訊息。透過 `ctx` 註冊的能力會在卸載時自動清理；計時器或網路連線等外部資源應使用 `ctx.effect()` 回傳 disposer。
