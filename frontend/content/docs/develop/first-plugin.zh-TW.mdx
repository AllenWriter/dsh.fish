---
title: 開發第一個外掛程式
description: 建立一個最小的 DeepSeek Harness 外掛程式，用原始碼 overlay 載入，並在 Web UI 中觀察它的執行。
---

DeepSeek Harness 由外掛程式組合而成。外掛程式是一個匯出 `apply` 函式的 TypeScript 模組。harness 載入外掛程式時會呼叫 `apply`，並傳入一個 Cordis context，外掛程式註冊的一切都經過這個物件。

本教學會做一個最小的外掛程式，把它載入 Web UI，再把它移除。流程在 DeepSeek Harness 原始碼倉庫中執行，請先完成官方的原始碼啟動步驟。

## 建立外掛程式

在倉庫根目錄建立一個暫存目錄：

```sh
mkdir -p scratch-plugin/src
```

建立 `scratch-plugin/src/my-plugin.ts`：

```ts
import type { Context } from '@deepseek-ai/cordis'

export const name = 'hello-plugin'

export function apply(ctx: Context): void {
  console.log('[hello-plugin] plugin loaded!')
}
```

透過 `ctx` 註冊的內容都是 effect：外掛程式卸載時 harness 會自動撤銷，不會在兩次載入之間留下殘留。

## 用原始碼 overlay 載入

原始碼 overlay 是一個 patch 檔案，把外掛程式插入組合後的設定，而不改動配置檔案本身。

執行 `pwd`，然後建立 `scratch-plugin/cordis.yml`，把範例路徑替換為原始碼倉庫的絕對路徑：

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

路徑必須是絕對路徑。patch 只提供設定，不改變載入器解析模組的目錄。

用 overlay 啟動 Web UI：

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

## 在 Web UI 中驗證

開啟 `http://127.0.0.1:3080`。啟動過程中終端會印出 `[hello-plugin] plugin loaded!`。發送一則訊息並觀察這次執行：Web UI 會列出每個步驟，包括模型的 Think 列和每次工具呼叫的輸入與輸出。

## 迭代與移除

修改外掛程式、儲存、再看結果。對配置檔案級和 home 級 `cordis.patch.yml` 檔案的修改會熱重載；新增、移除或重新建構已安裝的套件（bundle）則需要重新啟動。

對於 context 不管的資源，例如計時器或網路連線，在 `ctx.effect()` 裡取得它並回傳一個 disposer。外掛程式卸載時 harness 會執行這個 disposer。

要移除外掛程式，停掉指令，不帶 `--patch` 重新啟動即可。它的註冊會隨之消失。
