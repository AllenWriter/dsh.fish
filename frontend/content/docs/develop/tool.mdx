---
title: Register a tool
description: Add a typed tool to a DeepSeek Harness plugin and verify its input, result, and cleanup behavior.
---

A tool is an operation the model can request.

Keep it narrow: one clear outcome, every input validated, useful evidence returned, no hidden side effects.

## Define the tool

The essential shape is a stable name, a plain description, a schema, and an async handler. The example extends the scratch plugin from [Build your first plugin](/docs/develop/first-plugin):

```ts
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(
    defineTool({
      name: 'greet',
      description: 'Greet someone by name.',
      parameters: {
        name: {
          type: 'string',
          required: true,
          description: 'The name to greet',
        },
      },
      output: {
        schema: { type: 'string' },
        render: (_args, value) => [{ type: 'text', text: value }],
      },
      async execute(args) {
        return `Hello, ${args.name}!`
      },
    }),
  )
}
```

`inject` declares the services the plugin needs; the framework waits for each one before running `apply`, so `ctx.tools` is ready here.

`defineTool` infers and validates `args` from `parameters`.

`execute` returns the value declared by `output.schema`, and `output.render` converts that value into content the model sees.

Register inside `apply(ctx)`. Registrations through `ctx` are effects, so unloading the plugin removes the tool.

## Verify from both sides

1. Test the handler with valid, empty, and malformed input.
2. Start the Web UI with the overlay and ask: `Use the greet tool to greet Ada.`
3. Inspect the tool row's input and output, not only the assistant's reply.
4. Remove the plugin and confirm the tool disappears.

Do not put API keys in tool arguments or results. Resolve managed credentials through `ctx.credentials` at the start of each operation, and mask secrets in logs.

Official reference: [Build a tool](https://deepseek-harness.github.io/deepseek-harness/en/develop/basic/tool/).
