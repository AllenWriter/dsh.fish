Текущий официальный процесс разработки запускается из checkout исходного кода DeepSeek Harness. Сначала выполните официальную настройку запуска из исходников, затем создайте `scratch-plugin/src/my-plugin.ts` в корне репозитория.

```ts
import type { Context } from '@deepseek-ai/cordis'
export const name = 'hello-harness'
export function apply(ctx: Context): void {
  console.log('[hello-harness] plugin loaded!')
}
```

Создайте `scratch-plugin/cordis.yml` с абсолютным путём.

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

Откройте `http://127.0.0.1:3080` и проверьте сообщение загрузки в терминале. Регистрации через `ctx` очищаются автоматически; для таймеров и подключений используйте `ctx.effect()` с disposer.
