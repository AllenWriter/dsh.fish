DeepSeek Harness собирается из плагинов. Плагин — это TypeScript-модуль, который экспортирует функцию `apply`. При загрузке плагина harness вызывает `apply` и передаёт Cordis context — объект, через который плагин регистрирует всё, что добавляет.

В этом уроке мы соберём минимальный плагин, загрузим его в Web UI и удалим. Процесс работает из checkout исходного кода DeepSeek Harness, поэтому сначала выполните официальную настройку запуска из исходников.

## Создайте плагин

В корне репозитория создайте рабочую директорию:

```sh
mkdir -p scratch-plugin/src
```

Создайте `scratch-plugin/src/my-plugin.ts`:

```ts
import type { Context } from '@deepseek-ai/cordis'

export const name = 'hello-plugin'

export function apply(ctx: Context): void {
  console.log('[hello-plugin] plugin loaded!')
}
```

Всё, зарегистрированное через `ctx`, — это effect: при выгрузке плагина harness автоматически это отменяет, и между загрузками ничего не остаётся.

## Загрузите через source overlay

Source overlay — это patch-файл, который вставляет ваш плагин в итоговую конфигурацию, не меняя сам профиль.

Выполните `pwd` и создайте `scratch-plugin/cordis.yml`, заменив пример пути на абсолютный путь к checkout:

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

Путь должен быть абсолютным. Patch лишь добавляет конфигурацию и не меняет директорию, из которой загрузчик разрешает модули.

Запустите Web UI с overlay:

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

## Проверьте в Web UI

Откройте `http://127.0.0.1:3080`. При запуске терминал выводит `[hello-plugin] plugin loaded!`. Отправьте сообщение и посмотрите на запуск: Web UI перечисляет каждый шаг, включая строку Think модели и каждый вызов инструмента с входом и выходом.

## Итерации и удаление

Измените плагин, сохраните и проверьте результат снова. Правки `cordis.patch.yml` на уровне профиля и home применяются через горячую перезагрузку; добавление, удаление или пересборка установленного бандла требуют перезапуска.

Ресурс, которым context не управляет, например таймер или сетевое подключение, получайте внутри `ctx.effect()` и возвращайте disposer. Harness выполнит disposer при выгрузке плагина.

Чтобы удалить плагин, остановите команду и перезапустите без `--patch`. Его регистрации исчезнут вместе с ним.
