---
title: 注册工具
description: 为 DeepSeek Harness 插件添加一个类型化的工具，并验证它的输入、结果和清理行为。
---

工具是模型可以请求的操作。让它保持窄小：一个明确的结果，验证所有输入，返回有用的证据，不留隐藏副作用。

## 定义工具

基本结构是一个稳定的名字、一段平实的描述、一份 schema 和一个异步处理函数。下面的例子基于[开发第一个插件](/docs/develop/first-plugin)中的临时插件：

```ts
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(
    defineTool({
      name: 'greet',
      description: 'Greet someone by name.',
      parameters: {
        name: {
          type: 'string',
          required: true,
          description: 'The name to greet',
        },
      },
      output: {
        schema: { type: 'string' },
        render: (_args, value) => [{ type: 'text', text: value }],
      },
      async execute(args) {
        return `Hello, ${args.name}!`
      },
    }),
  )
}
```

`inject` 声明插件依赖的服务；框架会等每个服务就绪后才运行 `apply`，所以这里的 `ctx.tools` 已经可用。`defineTool` 根据 `parameters` 推断并校验 `args`。`execute` 返回 `output.schema` 声明的值，`output.render` 把这个值转换成模型看到的内容。

在 `apply(ctx)` 内注册。通过 `ctx` 的注册都是 effect，卸载插件时工具也会随之移除。

## 从两侧验证

1. 用有效、空白和错误输入测试处理函数。
2. 带 overlay 启动 Web UI，发送：`Use the greet tool to greet Ada.`
3. 检查工具行的输入和输出，而不只看助手的回答。
4. 移除插件，确认工具消失。

不要把 API 密钥放进工具的参数或返回值。在每次操作开始时通过 `ctx.credentials` 解析受管凭据，并在日志中遮盖敏感数据。
