現在の公式開発フローは DeepSeek Harness のソース checkout から実行します。公式のソース起動手順を終え、リポジトリ直下に `scratch-plugin/src/my-plugin.ts` を作成します。

```ts
import type { Context } from '@deepseek-ai/cordis'
export const name = 'hello-harness'
export function apply(ctx: Context): void {
  console.log('[hello-harness] plugin loaded!')
}
```

絶対パスを使う `scratch-plugin/cordis.yml` を作成します。

```yaml
- insert:
    - id: hello
      name: '/absolute/path/to/deepseek-harness/scratch-plugin/src/my-plugin.ts'
```

```sh
pnpm dsh web --patch ./scratch-plugin/cordis.yml
```

`http://127.0.0.1:3080` を開き、ターミナルの読み込みログを確認します。`ctx` 経由の登録はアンロード時に自動で消えます。タイマーや接続には disposer を返す `ctx.effect()` を使います。
