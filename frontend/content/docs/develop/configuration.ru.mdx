---
title: Настройте, упакуйте и установите плагин
description: Проверьте настройки, порядок переопределений profile и безопасную установку и удаление сборки.
---

Отклоняйте неверные настройки с ясной ошибкой, а не скрывайте проблему неявным значением по умолчанию.

Порядок композиции: profile bundles → profile `cordis.patch` → home `cordis.patch` → CLI patch. Поздний слой заменяет всю совпавшую строку, а не выполняет deep merge.

```sh
dsh --profile demo --dump-config
pnpm pack
dsh plugin --profile demo add ./hello-harness-0.1.0.tgz
```

Включите в пакет необходимые во время выполнения `lib/`, manifest, README и license. Тестируйте реальный tarball. Git-скрипт `prepare` работает вне песочницы, поэтому должен быть воспроизводимым; рекомендуйте фиксировать commit. После удаления убедитесь, что не осталось инструментов, файлов и фоновых ресурсов.
