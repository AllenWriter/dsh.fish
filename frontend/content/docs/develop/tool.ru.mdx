Инструмент — это операция, которую может запросить модель. Держите его узким: один ясный результат, проверка всех входных данных, полезные свидетельства в ответе, никаких скрытых побочных эффектов.

## Определите инструмент

Базовая форма — стабильное имя, простое описание, схема и асинхронный обработчик. Пример расширяет черновой плагин из урока [Создайте первый плагин](/docs/develop/first-plugin):

```ts
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(
    defineTool({
      name: 'greet',
      description: 'Greet someone by name.',
      parameters: {
        name: {
          type: 'string',
          required: true,
          description: 'The name to greet',
        },
      },
      output: {
        schema: { type: 'string' },
        render: (_args, value) => [{ type: 'text', text: value }],
      },
      async execute(args) {
        return `Hello, ${args.name}!`
      },
    }),
  )
}
```

`inject` объявляет сервисы, нужные плагину; фреймворк ждёт каждый из них перед запуском `apply`, поэтому `ctx.tools` здесь уже готов. `defineTool` выводит и проверяет `args` по `parameters`. `execute` возвращает значение, объявленное в `output.schema`, а `output.render` превращает это значение в контент для модели.

Регистрируйте внутри `apply(ctx)`. Регистрации через `ctx` — это effects, поэтому при выгрузке плагина инструмент исчезает.

## Проверьте с обеих сторон

1. Протестируйте обработчик на корректном, пустом и ошибочном вводе.
2. Запустите Web UI с overlay и спросите: `Use the greet tool to greet Ada.`
3. Изучите вход и выход в строке инструмента, а не только ответ ассистента.
4. Удалите плагин и убедитесь, что инструмент исчез.

Не помещайте API-ключи в аргументы и результаты инструмента. Разрешайте управляемые credentials через `ctx.credentials` в начале каждой операции и маскируйте секреты в логах.

Официальный справочник: [Build a tool](https://deepseek-harness.github.io/deepseek-harness/en/develop/basic/tool/)
