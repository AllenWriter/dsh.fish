DeepSeek Harness는 오픈 소스 에이전트 실행 환경입니다. dsh.fish는 Harness가 불러올 수 있는 확장을 찾고 검토하고 설치하는 독립 카탈로그입니다.

## 목적에 맞는 경로

- **처음 사용한다면:** [빠른 시작](/docs/quickstart)에서 Web UI, 모델, 작업 공간과 첫 작업을 설정하세요.
- **기능을 추가하려면:** 세션 안의 [Hub 플러그인](/docs/hub) 또는 터미널의 [dsh.fish CLI](/docs/cli)를 사용하세요. 설치 전에 계획을 확인합니다.
- **통합을 개발하려면:** [첫 플러그인](/docs/develop/first-plugin)을 만들고 [도구](/docs/develop/tool)와 [설정](/docs/develop/configuration)을 추가하세요.
- **공개하려면:** 알맞은 [게시 형식](/docs/publish/bundle)을 선택하고 소스를 제출한 뒤 공개 점수를 확인하세요.

dsh.fish는 실제 저장소나 패키지 manifest를 읽습니다. 웹사이트, CLI, Hub 플러그인은 같은 설치 계획 API를 사용합니다. Git 패키지의 빌드 스크립트는 에이전트 샌드박스 밖에서 실행되므로 별도의 명시적 승인이 필요합니다.

Harness는 개발자 프리뷰입니다. 버전별 세부 사항은 [공식 가이드](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart)를 확인하세요.
