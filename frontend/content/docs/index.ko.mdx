DeepSeek Harness(`dsh`)는 DeepSeek AI의 오픈 소스 에이전트 하니스로, 여러분의 컴퓨터에서 AI 에이전트를 실행하는 프로그램입니다. 선택한 모델을 파일을 읽고 수정하고 명령을 실행하는 도구에 연결하고, 에이전트가 하는 모든 일을 기록합니다.

`npx @deepseek-ai/dsh web`으로 로컬에서 시작하면 Web UI가 열립니다.

dsh.fish는 Harness 확장을 위한 독립 카탈로그입니다. 플러그인을 찾고 실제 내용을 읽은 뒤, 컴퓨터에 아무것도 쓰기 전에 설치 계획을 보여 줍니다.

웹사이트, dsh.fish CLI, 세션 안에서 실행되는 Hub 플러그인은 모두 같은 계획을 읽습니다.

## 학습 경로

사이드바는 처음부터 직접 만든 플러그인을 게시하기까지의 하나의 순서입니다.

1. **시작.** [빠른 시작](/docs/quickstart)은 빈 터미널에서 첫 작업 완료까지 안내하고, [핵심 개념](/docs/concepts)은 이후 모든 페이지가 사용하는 용어를 정의합니다.
2. **플러그인.** [플러그인](/docs/plugins)은 Harness가 플러그인 설치로 확장되는 방식을 설명하고, 형식별로 한 페이지씩 제공합니다: [bundle](/docs/publish/bundle), [skill](/docs/publish/skill), [agent preset](/docs/publish/agent-preset), [profile](/docs/publish/profile).
3. **개발.** 직접 만듭니다: [첫 플러그인](/docs/develop/first-plugin), [도구](/docs/develop/tool), 그 [설정](/docs/develop/configuration).
4. **dsh.fish 사용.** 세션 안의 [Hub 플러그인](/docs/hub) 또는 터미널의 [CLI](/docs/cli)로 검색하고 설치한 뒤, 직접 만든 것을 [제출](/docs/submit)합니다.
5. **참고.** [점수 산정](/docs/scoring) 방식과 카탈로그가 제공하는 [API](/docs/api).

## 설치를 신뢰할 수 있는 이유

카탈로그는 등록하는 모든 것의 실제 저장소 또는 패키지 manifest를 읽습니다. 토픽 태그나 제출은 발견의 출발점일 뿐입니다.

설치 계획은 실행 전에 읽을 수 있는 단계 목록으로, 추가할 패키지, 쓸 파일, 바꿀 설정이 담겨 있습니다.

빌드 스크립트를 실행해야 하는 Git 패키지는 해당 스크립트가 에이전트 샌드박스 밖에서 실행되므로 별도의 명시적 승인을 요청합니다.

## 개발자 프리뷰

DeepSeek Harness는 개발자 프리뷰 단계로, 호환성을 깨는 변경을 포함해 빠르게 바뀝니다. 이 문서는 게시된 npm 릴리스에서 검증한 동작만 다룹니다.

버전별 옵션은 [공식 가이드](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart)를 참조하세요.
