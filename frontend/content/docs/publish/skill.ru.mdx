Skill — Markdown-файл с инструкциями, который агент может загрузить, когда этого требует задача. Для skill не нужен пакетный менеджер: они устанавливаются как обычные файлы в `$DSH_HOME/skills`.

## Манифест-контракт

Skill — это либо каталог с одним `SKILL.md`, либо один плоский файл `.md`. В обоих случаях есть YAML frontmatter:

```md
---
name: release-notes
description: Draft release notes from a commit range.
---

# Release notes

Steps the agent should follow…
```

`name` должен быть в kebab-case, а `description` обязателен. Файл без любого из них провайдер skill игнорирует с предупреждением.

## Установка и публикация

План установки записывает файлы skill в `$DSH_HOME/skills`: skill в виде каталога сохраняет свою папку, плоский skill становится `<name>.md`. Ни шаг сборки, ни строка patch здесь не участвуют.

Индексатор доказывает skill, читая сам файл, после проверок манифеста пакета.

Отправка может нести `kindHint` со значением `skill`, чтобы `SKILL.md` читался первым, но подсказка не заменяет доказательство: файл, не являющийся корректным skill, переходит к остальным проверкам.
