title: Skill
description: Публикуйте навыки агентов через SKILL.md с именем в kebab-case и обязательным описанием.
---

Skill — файл `SKILL.md` с frontmatter, устанавливаемый в `$DSH_HOME/skills`.

```md
---
name: release-notes
description: Draft release notes from a commit range.
---
```

`name` должен быть в kebab-case, а `description` обязателен. `kindHint` меняет только порядок проверки и не заменяет корректный файл.
