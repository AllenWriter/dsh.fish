---
title: Profiles
description: A profile lists bundles in order. Later layers win per row, and a patch replaces a row’s whole config rather than deep-merging it.
---

A profile is an ordered `dsh.profile.bundles` stack. The indexer installs one `add` per bundle, in order.

```json
{
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "dsh-hello-plugin"]
    }
  }
}
```

Later layers win per row, and a patch replaces a row’s whole config rather than deep-merging it — so order is meaningful.

This probe runs first. A package that is both a profile and a bundle is a profile, because a profile _is_ an ordered stack of bundles.
