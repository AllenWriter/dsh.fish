title: Hook Bridge

---

Hook bridge는 Claude Code나 Codex용으로 작성해 둔 shell hook을 DeepSeek Harness 안에서 실행합니다. MCP server와 마찬가지로 Harness에는 이런 종류의 아티팩트에 대한 매니페스트 규약이 없고(profile patch의 bridge 플러그인 행으로 설치되므로), `package.json`의 `dsh.hub` 선언이 정보 원본입니다.

## 매니페스트 규약

```json
{
  "dsh": {
    "hub": {
      "kind": "hook-bridge",
      "hook": {
        "dialect": "claude-code",
        "settingsPath": "hooks/settings.json"
      }
    }
  }
}
```

- `dialect`는 `claude-code` 또는 `codex`로, settings 파일이 어느 도구의 hook 형식으로 작성됐는지를 나타냅니다.
- `settingsPath`는 그 파일을 가리키는 저장소 상대 경로입니다. 절대 경로나 저장소를 벗어나는 경로는 거부됩니다.

불완전한 선언(kind만 있고 블록이 없거나, 알 수 없는 dialect, 저장소 밖 경로)은 domain error입니다. 인덱서는 해당 저장소를 건너뛰고 오류를 기록하며, 직접 제출한 저장소라면 그 오류가 반환됩니다.

## settings 파일

`settingsPath`는 일반적인 Claude Code settings 파일(`hooks.json` 또는 `hooks` 키가 있는 settings 파일)을 가리킵니다.

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "bash",
        "hooks": [
          { "type": "command", "command": "./scripts/check-command.sh" }
        ]
      }
    ]
  }
}
```

matcher가 검사하는 대상은 도구 이름이며 `type: "command"` hook만 실행됩니다. Claude Code 방언은 일곱 가지 이벤트를 지원합니다: `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`, `SubagentStart`, `SubagentStop`. Codex 방언은 같은 이벤트 맵 형태로 그중 다섯 가지(`SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`)를 지원하며 동기 command hook만 실행합니다.

## 설치 방식

설치 계획은 해당 프로필의 `cordis.patch.yml` 계층에 bridge 플러그인 행(`@deepseek-ai/dsh-hooks-claude-code` 또는 `@deepseek-ai/dsh-hooks-codex`)을 하나 추가합니다.

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

Hook bridge는 settings 파일의 shell 명령을 에이전트 권한으로 실행합니다. 설치 전에 그 파일을 읽어 보세요.
