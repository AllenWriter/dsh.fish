配置档案（profile）是一个有序的 bundle 列表，合起来构成完整、可运行的 Harness 组合。

这个词指代两个不同的东西。本页讲的构件是发布出来的 bundle 列表。运行时 `--profile` 标志选择启动哪个本地组合：`dsh --profile web` 运行存放在 `$DSH_HOME/profiles/web` 的配置档案。

安装 profile 构件，是把它的 bundle 按顺序加入你选定的一个本地配置档案，之后用该标志启动它。

## 清单契约

包通过 `dsh.profile.bundles` 声明 profile：

```json
{
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "dsh-hello-plugin"]
    }
  }
}
```

每个 profile 都从 `@deepseek-ai/dsh-base`（共享核心层）开始。后面的层按行胜出。patch 会整体替换一行的配置而不是深度合并，所以顺序会改变结果。

同时声明 `dsh.profile` 和 `dsh.bundle` 的包会被归类为 profile，因为 profile 本身就是一个有序的 bundle 栈。

## 安装与发布

安装计划逐个接纳 profile 的 bundle，按声明顺序每个执行一次安装：

```sh
dsh plugin --profile web add @deepseek-ai/dsh-base
dsh plugin --profile web add dsh-hello-plugin
```

`dsh plugin add` 在首次使用时创建本地配置档案，以 `@deepseek-ai/dsh-base` 为第一个 bundle，然后依次追加其余 bundle。

要发布，向 dsh.fish [提交](/docs/submit)包。注册表读取的是同一份 `dsh.profile.bundles` 列表。
