Agent preset은 바로 쓸 수 있는 에이전트입니다. persona가 에이전트가 누구인지를 정하고 도구 선택이 무엇을 할 수 있는지를 정하며, 둘이 하나의 `agent.cordis.yml` 파일에 담깁니다. 세션은 id로 preset을 골라 바로 그 에이전트를 얻습니다.

이 파일은 Cordis 플러그인 행의 목록입니다. `@deepseek-ai/dsh-persona` 행이 정체성을 설정하고 각 도구 행이 기능을 하나씩 추가합니다.

## 매니페스트 규약

preset은 `agent.cordis.yml` 하나가 든 디렉터리이며, 저장소 루트나 제출한 하위 디렉터리에 둡니다.

```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    text: >-
      You are a careful code reviewer powered by the {{model}} model.

- id: tool-fs
  name: '@deepseek-ai/dsh-tool-fs'

- id: tool-fs-search
  name: '@deepseek-ai/dsh-tool-fs-search'
```

preset id는 저장소(디렉터리) 이름에서 나오며 소문자 kebab-case로 변환됩니다. `[a-z0-9][a-z0-9-]*`와 일치해야 합니다.

preset 검사는 마지막에 실행됩니다. `package.json`이 bundle 또는 profile을 선언하거나 `SKILL.md`를 둔 저장소는 더 앞선 검사에서 분류됩니다.

## 설치 방식

preset을 설치하면 그 파일이 `$DSH_HOME/.agent-presets/<id>/agent.cordis.yml`에 기록됩니다.

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

Harness는 이 디렉터리를 preset 루트로 스캔하므로 새 세션이 바로 이 preset을 고를 수 있습니다. preset은 나열한 플러그인과 같은 권한으로 실행되므로 설치 전에 파일을 읽어 보세요.
