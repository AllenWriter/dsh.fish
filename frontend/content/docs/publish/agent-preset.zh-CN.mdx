---
title: Agent Preset
description: Agent preset 把一个智能体（persona 加工具选择）打包进一个 agent.cordis.yml 文件。
---

Agent preset 是一个现成的智能体：persona 决定它是谁，工具选择决定它能做什么，两者打包在一个 `agent.cordis.yml` 文件里。会话按 id 选用 preset，得到的就是这个智能体。

该文件是一份 Cordis 插件行列表。`@deepseek-ai/dsh-persona` 行设定身份，每个工具行增加一项能力。

## 清单约定

preset 是只含一个 `agent.cordis.yml` 的目录，文件放在仓库根目录或提交的子目录中：

```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    text: >-
      You are a careful code reviewer powered by the {{model}} model.

- id: tool-fs
  name: '@deepseek-ai/dsh-tool-fs'

- id: tool-fs-search
  name: '@deepseek-ai/dsh-tool-fs-search'
```

preset id 取自仓库（目录）名，会转换为小写 kebab-case，必须匹配 `[a-z0-9][a-z0-9-]*`。

preset 探针最后运行。如果仓库的 `package.json` 已声明 bundle、profile、MCP server 或 hook bridge（或者仓库带有 `SKILL.md`），就会被更早的探针分类。

## 安装机制

安装 preset 会把文件写入 `$DSH_HOME/.agent-presets/<id>/agent.cordis.yml`：

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

Harness 把该目录作为 preset 根目录扫描，新会话随即可以选用这个 preset。preset 的权限与它列出的每个插件相同，安装前请先读一遍文件内容。
