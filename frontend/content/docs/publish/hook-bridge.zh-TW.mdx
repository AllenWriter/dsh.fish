---
title: Hook Bridge
description: 在 DeepSeek Harness 中執行你為 Claude Code 或 Codex 寫好的 shell hooks。
---

Hook bridge 把你為 Claude Code 或 Codex 寫好的 shell hooks 搬進 DeepSeek Harness 執行。和 MCP server 一樣，Harness 沒有為這種構件定義清單慣例（它安裝為 profile patch 中的一列 bridge 外掛設定），所以 `package.json` 裡的 `dsh.hub` 宣告是資料來源。

## 清單慣例

```json
{
  "dsh": {
    "hub": {
      "kind": "hook-bridge",
      "hook": {
        "dialect": "claude-code",
        "settingsPath": "hooks/settings.json"
      }
    }
  }
}
```

- `dialect` 為 `claude-code` 或 `codex`，表示 settings 檔案使用哪種工具的 hook 格式。
- `settingsPath` 指向該檔案，相對於儲存庫。絕對路徑或越出儲存庫的路徑會被拒絕。

宣告殘缺（只有 kind 沒有對應區塊、dialect 無效、路徑越出儲存庫）是 domain error。indexer 會略過該儲存庫並記錄錯誤；如果是你自己提交的儲存庫，錯誤會回傳給你。

## settings 檔案

`settingsPath` 指向一個普通的 Claude Code settings 檔案（`hooks.json`，或任何帶 `hooks` 鍵的 settings 檔案）：

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "bash",
        "hooks": [
          { "type": "command", "command": "./scripts/check-command.sh" }
        ]
      }
    ]
  }
}
```

matcher 比對的是工具名稱，只有 `type: "command"` 的 hook 會執行。Claude Code 方言支援七個事件：`SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`Stop`、`SubagentStart`、`SubagentStop`。Codex 方言使用相同的事件對應結構，支援其中五個（`SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`Stop`），且只執行同步的 command hook。

## 安裝機制

安裝計畫會在該 profile 的 `cordis.patch.yml` 層附加一列 bridge 外掛，即 `@deepseek-ai/dsh-hooks-claude-code` 或 `@deepseek-ai/dsh-hooks-codex`：

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

Hook bridge 會以代理的權限執行 settings 檔案裡的 shell 命令。安裝前請先讀一遍這個檔案。
