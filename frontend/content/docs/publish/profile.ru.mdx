Профиль (profile) — упорядоченный список bundle, которые вместе образуют законченную, работоспособную композицию Harness.

Это слово называет две разные вещи. Артефакт на этой странице — опубликованный список bundle. Флаг времени выполнения `--profile` выбирает, какая локальная композиция загружается: `dsh --profile web` запускает профиль из `$DSH_HOME/profiles/web`.

Установить артефакт «профиль» — значит добавить его bundle по порядку в выбранный вами локальный профиль. Затем вы загружаете этот профиль флагом.

## Манифест-контракт

Пакет объявляет profile через `dsh.profile.bundles`:

```json
{
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "dsh-hello-plugin"]
    }
  }
}
```

Каждый профиль начинается с `@deepseek-ai/dsh-base`, общего слоя ядра. Поздний слой побеждает по строке. Patch заменяет всю конфигурацию строки вместо глубокого слияния, поэтому порядок меняет результат.

Пакет, объявляющий и `dsh.profile`, и `dsh.bundle`, классифицируется как profile, потому что profile сам по себе — упорядоченный стек bundle.

## Установка и публикация

План установки принимает профиль по одному bundle за раз, по одному добавлению на запись в объявленном порядке:

```sh
dsh plugin --profile web add @deepseek-ai/dsh-base
dsh plugin --profile web add dsh-hello-plugin
```

`dsh plugin add` создаёт локальный профиль при первом использовании с `@deepseek-ai/dsh-base` в качестве первого bundle, затем добавляет каждый следующий bundle.

Чтобы опубликовать, [отправьте](/docs/submit) пакет на dsh.fish. Реестр читает тот же список `dsh.profile.bundles`.
