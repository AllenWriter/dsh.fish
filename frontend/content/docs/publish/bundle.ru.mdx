Bundle — npm-пакет, который вносит плагины в Harness одним слоем patch. Это стандартная единица распространения возможностей Harness.

## Манифест-контракт

Пакет становится bundle, объявляя `dsh.bundle.patch` в своём `package.json` и указывая на patch-файл Cordis:

```json
{
  "name": "dsh-hello-plugin",
  "version": "0.1.0",
  "type": "module",
  "files": ["index.js", "cordis.patch.yml"],
  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
}
```

Patch-файл перечисляет строки плагинов, которые вставляет слой. Именно объявление определяет bundle: пакет без него по-прежнему установится как обычная зависимость, но Harness не активирует для него ни одного слоя, а каталог dsh.fish не перечислит его как плагин.

## Установка и публикация

План установки bundle — одно добавление пакета в профиль:

```sh
npx @dsh-fish/cli add dsh-hello-plugin --profile web
# нативная команда Harness:
dsh plugin --profile web add dsh-hello-plugin
```

Публикуйте в npm уже собранный код, чтобы пользователям не требовалось разрешение на сборку. Установка из git получает исходники: предоставьте самодостаточный скрипт `prepare` и ожидайте, что пользователи внесут его в список разрешённых, потому что pnpm запускает этот скрипт во время установки вне песочницы агента.

Чтобы опубликовать, [отправьте](/docs/submit) пакет или репозиторий на dsh.fish. Реестр заново читает реальный манифест, поэтому объявление должно быть в опубликованном `package.json`.
