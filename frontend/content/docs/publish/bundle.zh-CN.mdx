Bundle 是把插件以一层 patch 的形式带入 Harness 的 npm 包，是分发 Harness 能力的标准单元。

## 清单契约

包通过在 `package.json` 中声明 `dsh.bundle.patch` 成为 bundle，指向一个 Cordis patch 文件：

```json
{
  "name": "dsh-hello-plugin",
  "version": "0.1.0",
  "type": "module",
  "files": ["index.js", "cordis.patch.yml"],
  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
}
```

patch 文件列出该层插入的插件行。

声明定义了 bundle。没有该声明的包：

- 仍可作为普通依赖安装，
- 但 Harness 不会为它激活任何层，
- dsh.fish 目录也不会把它列为插件。

## 安装与发布

bundle 的安装计划是向配置档案执行一次包管理器安装：

```sh
npx @dsh-fish/cli add dsh-hello-plugin --profile web
# Harness 原生命令：
dsh plugin --profile web add dsh-hello-plugin
```

发布到 npm 时应附带预构建代码，用户就无需构建许可。

git 安装拉取的是源码：请提供自包含的 `prepare` 脚本。预期用户会将其加入允许列表，因为 pnpm 会在安装时、在智能体沙箱之外运行该脚本。

要发布，向 dsh.fish [提交](/docs/submit)包或仓库。注册表会重新读取真实清单，所以声明必须存在于已发布的 `package.json` 中。
