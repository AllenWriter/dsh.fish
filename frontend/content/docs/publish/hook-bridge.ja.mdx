---
title: Hook Bridge
description: 既存の Claude Code または Codex shell hook を DeepSeek Harness で実行します。
---

Hook bridge は profile patch に bridge plugin 行として追加され、`dsh.hub` が情報源です。

```json
{
  "dsh": {
    "hub": {
      "kind": "hook-bridge",
      "hook": {
        "dialect": "claude-code",
        "settingsPath": "hooks/settings.json"
      }
    }
  }
}
```

`dialect` は `claude-code` または `codex` です。`settingsPath` はリポジトリ相対でなければならず、外へ出るパスは拒否されます。不完全な宣言や種類の不一致は明示的なエラーになります。
