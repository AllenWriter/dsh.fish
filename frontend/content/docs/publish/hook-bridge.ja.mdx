---
title: Hook Bridge
description: Claude Code や Codex 用に書いた既存の shell hook を DeepSeek Harness で実行します。
---

Hook bridge は、あなたが Claude Code や Codex 用に書いた shell hook を DeepSeek Harness の中で実行します。MCP server と同じく、Harness にはこの種のアーティファクト向けのマニフェスト規約がなく（profile patch の bridge プラグイン行として導入されるため）、`package.json` の `dsh.hub` 宣言が情報源です。

## マニフェスト規約

```json
{
  "dsh": {
    "hub": {
      "kind": "hook-bridge",
      "hook": {
        "dialect": "claude-code",
        "settingsPath": "hooks/settings.json"
      }
    }
  }
}
```

- `dialect` は `claude-code` または `codex` で、settings ファイルがどちらのツールの hook 形式で書かれているかを示します。
- `settingsPath` はそのファイルを指すリポジトリ相対パスです。絶対パスやリポジトリ外へ出るパスは拒否されます。

不完全な宣言（kind だけでブロックがない、不明な dialect、リポジトリ外のパス）は domain error です。インデクサはそのリポジトリをスキップしてエラーを記録し、自分で送信したリポジトリであればそのエラーが返されます。

## settings ファイル

`settingsPath` は通常の Claude Code settings ファイル（`hooks.json`、または `hooks` キーを持つ settings ファイル）を指します。

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "bash",
        "hooks": [
          { "type": "command", "command": "./scripts/check-command.sh" }
        ]
      }
    ]
  }
}
```

matcher が照合するのはツール名で、実行されるのは `type: "command"` の hook だけです。

Claude Code 方言は 7 つのイベントをサポートします：

- `SessionStart`
- `UserPromptSubmit`
- `PreToolUse`
- `PostToolUse`
- `Stop`
- `SubagentStart`
- `SubagentStop`

Codex 方言は同じイベントマップ形式で、そのうち 5 つをサポートし、同期の command hook のみを実行します：

- `SessionStart`
- `UserPromptSubmit`
- `PreToolUse`
- `PostToolUse`
- `Stop`

## 導入の仕組み

インストールプランは、そのプロファイルの `cordis.patch.yml` レイヤーに bridge プラグインの行（`@deepseek-ai/dsh-hooks-claude-code` または `@deepseek-ai/dsh-hooks-codex`）を 1 行追加します。

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

Hook bridge は settings ファイル内の shell コマンドをエージェントの権限で実行します。導入前にそのファイルを読んでください。
