Skill 是一个 Markdown 指令文件，智能体在任务需要时加载它。Skill 不需要包管理器：它们作为普通文件安装到 `$DSH_HOME/skills` 下。

## 清单契约

Skill 可以是一个仅含 `SKILL.md` 的目录，也可以是单个扁平的 `.md` 文件。两种形式都带 YAML frontmatter：

```md
---
name: release-notes
description: Draft release notes from a commit range.
---

# Release notes

Steps the agent should follow…
```

`name` 必须是 kebab-case，`description` 必填。缺少任一项的文件会被 skill provider 忽略，并记录一条警告。

## 安装与发布

安装计划把 skill 的文件写入 `$DSH_HOME/skills`：目录形式的 skill 保留其文件夹，扁平 skill 成为 `<name>.md`。不涉及构建步骤，也不涉及 patch 行。

索引器在包清单检查之后，通过读取文件本身来证明 skill。提交可以携带 `skill` 的 `kindHint`，让 `SKILL.md` 最先被读取，但提示不能代替证据：不是有效 skill 的文件会落入其余检查。
