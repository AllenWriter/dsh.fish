A hook bridge runs the shell hooks you already wrote for Claude Code or Codex inside DeepSeek Harness. Like an MCP server, this kind has no harness manifest convention (it installs as a bridge plugin row in the profile patch), so the `dsh.hub` declaration in `package.json` is the source of truth.

## Manifest contract

```json
{
  "dsh": {
    "hub": {
      "kind": "hook-bridge",
      "hook": {
        "dialect": "claude-code",
        "settingsPath": "hooks/settings.json"
      }
    }
  }
}
```

- `dialect` is `claude-code` or `codex`: which tool's hook format the settings file is written in.
- `settingsPath` points at that file, relative to the repository. An absolute path or one that escapes the repository is rejected.

A malformed declaration (a kind without its block, an unknown dialect, a path that leaves the repo) is a domain error. The indexer skips the repository and records the error; if you submitted the repository yourself, the error comes back to you.

## The settings file

`settingsPath` points at a normal Claude Code settings file (a `hooks.json`, or any settings file with a `hooks` key):

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "bash",
        "hooks": [
          { "type": "command", "command": "./scripts/check-command.sh" }
        ]
      }
    ]
  }
}
```

The matcher tests the tool name, and only `type: "command"` hooks run. The Claude Code dialect supports seven events: `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`, `SubagentStart`, `SubagentStop`. The Codex dialect uses the same event-map shape and supports five of them (`SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`), running synchronous command hooks only.

## How it installs

The install plan appends one bridge plugin row, `@deepseek-ai/dsh-hooks-claude-code` or `@deepseek-ai/dsh-hooks-codex`, to the profile's `cordis.patch.yml` layer:

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

A hook bridge runs shell commands from the settings file with the agent's permissions. Read the file before installing it.
