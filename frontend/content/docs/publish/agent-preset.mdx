---
title: Agent presets
description: An agent preset packs one agent — its persona and its tool selection — into a single agent.cordis.yml file.
---

An agent preset is a ready-made agent: a persona that says who the agent is, plus a tool selection that says what it can do, packed into one `agent.cordis.yml` file. A session picks a preset by id and gets exactly that agent.

The file is a list of Cordis plugin rows. A `@deepseek-ai/dsh-persona` row sets the identity; each tool row adds one capability.

## Manifest contract

A preset is a directory holding one `agent.cordis.yml`, placed at the repository root or in the submitted subdirectory:

```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    text: >-
      You are a careful code reviewer powered by the {{model}} model.

- id: tool-fs
  name: '@deepseek-ai/dsh-tool-fs'

- id: tool-fs-search
  name: '@deepseek-ai/dsh-tool-fs-search'
```

The preset id comes from the repository (directory) name, slugified to lowercase kebab-case: it must match `[a-z0-9][a-z0-9-]*`.

The preset probe runs last. A repository whose `package.json` declares a bundle, profile, MCP server, or hook bridge (or one that ships a `SKILL.md`) is classified by that earlier probe instead.

## How it installs

Installing a preset writes the file to `$DSH_HOME/.agent-presets/<id>/agent.cordis.yml`:

```sh
npx @dsh-fish/cli add <artifact-id> --profile <profile>
```

The harness scans that directory as a preset root, so new sessions can pick the preset immediately. A preset runs with the permissions of every plugin it names, so read the file before installing it.
