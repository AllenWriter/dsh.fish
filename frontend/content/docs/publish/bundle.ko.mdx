---
title: Bundle
description: dsh.bundle.patch로 DeepSeek Harness가 활성화할 수 있는 npm 플러그인 패키지를 선언합니다.
---

Bundle은 `dsh.bundle.patch`를 선언하는 npm 패키지이며 `dsh plugin add`의 설치 단위입니다.

```json
{
  "name": "dsh-hello-plugin",
  "files": ["index.js", "cordis.patch.yml"],
  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
}
```

이 선언이 없으면 패키지가 설치되어도 Harness 레이어가 활성화되지 않습니다. npm에는 미리 빌드한 코드를 배포하세요. Git 설치에서 `prepare`를 쓰면 사용자가 빌드 스크립트를 명시적으로 허용해야 합니다.
