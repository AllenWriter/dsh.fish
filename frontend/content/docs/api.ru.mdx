Публичный API предназначен для поиска и интеграций только для чтения. Начните со сгенерированного [OpenAPI-документа](/openapi.json); на этой странице — самый короткий полезный путь.

## Поиск артефактов

```sh
curl -s 'https://dsh.fish/api/v1/artifacts?q=postgres&kind=mcp-server'
```

Используйте возвращённый стабильный `id` с эндпоинтами деталей и плана установки:

```sh
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID'
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/install-plan?profile=web'
```

План установки — это данные, а не команда для слепого запуска. Покажите пользователю каждый файл, пакет и патч профиля. Если пакету нужно разрешение на сборку, запросите подтверждение отдельно.

## Чтение сигналов доверия

```sh
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/reviews'
curl -s 'https://dsh.fish/api/v1/scoring'
```

Эндпоинт оценки возвращает ту же модель, что показывает [справка об оценке](/docs/scoring). Не копируйте формулу в свой код как независимую константу.

## Зеркалирование каталога

Сторонние каталоги и боты могут хранить локальную копию всего каталога, не обходя страницы. Опрашивайте лёгкий эндпоинт version и скачивайте новый снимок только при изменении `dataVersion`:

```sh
curl -s 'https://dsh.fish/api/v1/catalog/version'
curl -s 'https://dsh.fish/api/v1/catalog/snapshot' -o catalog.json
```

Храните снимок вместе с версией и `ETag` и отправляйте `If-None-Match` при последующих загрузках; если каталог не изменился, ответом будет 304. Публичное чтение не требует учётной записи; для авторизованных операций записи используются области, описанные в OpenAPI.
