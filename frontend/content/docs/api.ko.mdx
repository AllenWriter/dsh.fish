공개 API는 검색과 읽기 전용 카탈로그 통합에 사용합니다. 생성된 [OpenAPI 문서](/openapi.json)를 먼저 보세요. 이 페이지는 가장 짧은 사용 경로만 보여 줍니다.

## 아티팩트 검색

```sh
curl -s 'https://dsh.fish/api/v1/artifacts?q=postgres&kind=mcp-server'
```

반환된 안정적인 `id`로 상세 정보와 설치 계획 엔드포인트를 호출합니다.

```sh
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID'
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/install-plan?profile=web'
```

설치 계획은 데이터이며 그대로 실행하는 대상이 아닙니다. 모든 파일, 패키지, 프로필 패치를 사용자에게 보여 주세요. 패키지에 빌드 허용이 필요하면 별도로 확인을 받으세요.

## 신뢰 신호 읽기

```sh
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/reviews'
curl -s 'https://dsh.fish/api/v1/scoring'
```

점수 엔드포인트가 반환하는 모델은 [점수 안내](/docs/scoring)가 렌더링하는 것과 같습니다. 공식을 자신의 코드에 상수로 복사하지 마세요.

## 카탈로그 미러링

서드파티 디렉터리와 봇은 크롤링 없이 카탈로그 전체의 복사본을 로컬에 유지할 수 있습니다. 가벼운 version 엔드포인트를 폴링하고 `dataVersion`이 바뀔 때만 새 스냅숏을 내려받으세요.

```sh
curl -s 'https://dsh.fish/api/v1/catalog/version'
curl -s 'https://dsh.fish/api/v1/catalog/snapshot' -o catalog.json
```

스냅숏은 버전 및 `ETag`와 함께 저장하고, 이후 다운로드에는 `If-None-Match`를 보내세요. 카탈로그가 바뀌지 않았다면 304만 돌아옵니다.

공개 읽기에는 계정이 필요 없으며, 인증이 필요한 쓰기 작업은 OpenAPI에 설명된 스코프를 사용합니다.
