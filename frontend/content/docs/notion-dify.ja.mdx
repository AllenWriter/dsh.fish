## ライブラリは、置いてあるだけでは使えない

Notion は知識を置く場所としてよくできている。個人のライブラリにも、共同作業の場にもなる。柔軟で、拡張も多い。

ただ、その知識は基本的に静止している。使うには自分で検索し、ページを開き、目的の一文まで読む。量が少ないうちはそれで足りる。ワークスペースが大きくなると、速さも賢さも足りなくなる。

私は、自分の Notion を読んだアシスタントが欲しかった。復習を手伝ってくれ、屋敷を知る執事のように会話を続け、他人の質問にも主人が答えるように返せるもの。

## Dify で実現する

[Dify](https://dify.ai/) はオープンソースの LLMOps プラットフォームだ。ChatGPT や Claude は、渡したテキストから学習できる。足りないのはモデルそのものより、Notion のページをモデルが使える文脈に変える側であることが多い。

Dify を使わなければ、同じパイプラインを LangChain などで自分で組むことになる。分割、ベクトル、検索、対話。Dify はデータセット、学習、プロンプト、チャットアプリを一枚の画面にまとめている。

## 五つの手順

流れは短い。

1. Dify にログインする
2. データセットを作る
3. Notion を接続する
4. 学習を走らせる
5. アプリを作り、データセットを載せる

### 1. Dify にログインする

[dify.ai](https://dify.ai/) を開き、GitHub か Google で入る。GitHub を使うなら [langgenius/dify](https://github.com/langgenius/dify) に star を付けると、メンテナの助けになる。

### 2. データセットを作る

上のバーで **Datasets** を押し、**Create Dataset** を押す。

### 3. Notion を接続する

**Sync from Notion** を選び、**Connect** を押す。

Notion のログイン画面に飛ぶ。権限を確認し、**Select pages** を押す。

同期したいページを選び、**Allow access** を押す。

### 4. 学習を始める

モデルに読ませるページを指定して進む。

分割は **Automatic**、品質は **High Quality** を選んだ。**Save & Process** を押して待つ。コーヒーを淹れるくらいの待ち時間で、監視するほどではない。

### 5. アプリを作る

データセットだけでは会話しない。ダッシュボードに戻り、**Create new APP**、Chat アプリで始める。

**Prompt Eng.** を開き、**context** に Notion のデータセットを載せる。

事前プロンプトは書いた方がいい。ノートが開発の切り分け中心なら、例えば次のような文で足りる。

> 私の Notion ワークスペースの IT 専門家として振る舞ってください。コンピュータサイエンス、ネットワーク、これらのノート、セキュリティの知識を使って問題を解いてください。

最初の一文を出して、何を聞いてよいか示すのも有効だった。Speech to Text を入れると、声でも話せる。

右上の **Publish**。Overview の公開 URL が対話の入口になる。

## 自分のプロジェクトから API で呼ぶ

Dify のアプリには API が付く。モデルと検索は Dify 側、フロントはメッセージを送るだけ、いわゆる BaaS になる。

Overview から **API Reference** を開く。それがそのアプリの契約書だ。

### シークレットを発行する

アプリ用に新しい API secret を作る。既にクライアントへ配った鍵は使い回さない。

### conversation id を取る

一度チャットしたあと、**Logs & Ann.** にセッション ID が出る。

### リクエストを送る

ドキュメントのサンプルを使う。シークレットを差し替える。初回は `conversation_id` を空にし、レスポンスの id を次のターンに入れる。

```bash
curl --location --request POST 'https://api.dify.ai/v1/chat-messages' \
--header 'Authorization: Bearer ENTER-YOUR-SECRET-KEY' \
--header 'Content-Type: application/json' \
--data-raw '{
    "inputs": {},
    "query": "eh",
    "response_mode": "streaming",
    "conversation_id": "",
    "user": "abc-123"
}'
```

成功するとストリームが返る。

同じ会話を続けるなら、返ってきた `conversation_id` を次のリクエストに入れる。履歴は Logs に残る。

## Notion との同期

ページが更新されたら、定期的に Dify 側で同期する。新しい文を学習させるためだ。

## 残るもの

残るのは「Notion に AI を被せた」という話ではない。更新できるデータセット、書き直せるプロンプト、既に出荷しているものから呼べる API だ。Dify は、LangChain を手で組まなくて済む一道である。
