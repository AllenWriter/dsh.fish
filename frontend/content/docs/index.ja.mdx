DeepSeek Harness(`dsh`)は DeepSeek AI のオープンソースのエージェントハーネスで、自分のマシン上で AI エージェントを動かすプログラムです。選んだモデルにファイルの読み書きやコマンド実行のツールを接続し、エージェントの動作をすべて記録します。`npx @deepseek-ai/dsh web` でローカルに起動すると、Web UI が開きます。

dsh.fish は Harness 拡張の独立カタログです。プラグインを見つけ、実際の内容を読み取り、マシンに何も書き込まれる前にインストールプランを確認できます。Web サイト、dsh.fish CLI、セッション内で動く Hub プラグインは、すべて同じプランを読みます。

## 学習パス

サイドバーは、ゼロから自分のプラグインを公開するまでの一連の順序になっています。

1. **はじめる**。[クイックスタート](/docs/quickstart)で空のターミナルから最初のタスク完了まで進み、[基本概念](/docs/concepts)で以降のページが使う語彙を定義します。
2. **プラグイン**。[プラグインについて](/docs/plugins)で Harness がプラグインのインストールで拡張される仕組みを説明し、形式ごとに 1 ページずつ用意しています: [bundle](/docs/publish/bundle)、[skill](/docs/publish/skill)、[MCP server](/docs/publish/mcp-server)、[agent preset](/docs/publish/agent-preset)、[profile](/docs/publish/profile)、[hook bridge](/docs/publish/hook-bridge)。
3. **開発**。自分で作ります: [最初のプラグイン](/docs/develop/first-plugin)、[ツール](/docs/develop/tool)、その[設定](/docs/develop/configuration)。
4. **dsh.fish を使う**。セッション内の [Hub プラグイン](/docs/hub)またはターミナルの [CLI](/docs/cli)で検索・インストールし、自分の成果物を[登録](/docs/submit)します。
5. **リファレンス**。[スコアリング](/docs/scoring)の仕組みと、カタログが公開する [API](/docs/api)。

## インストールを信頼できる理由

カタログは掲載するすべてのものについて、実際のリポジトリまたはパッケージ manifest を読みます。トピックタグや投稿は発見の入り口にすぎません。インストールプランは、実行前に読めるステップの一覧です。追加するパッケージ、書き込むファイル、変更する設定が含まれます。ビルドスクリプトが必要な Git パッケージは、そのスクリプトがエージェントのサンドボックス外で実行されるため、別途明示的な許可を求めます。

## 開発者プレビュー

DeepSeek Harness は開発者プレビューであり、互換性を壊す変更を含めて速いペースで更新されます。このドキュメントは公開された npm リリースで検証した動作だけを記載しています。バージョン固有の選択肢は[公式ガイド](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart)を参照してください。
