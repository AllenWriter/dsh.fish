`@dsh-fish/cli`는 터미널에서 [dsh.fish](https://dsh.fish) 아티팩트를 설치합니다. 아티팩트 페이지의 설치 명령이 이 바이너리이며, 웹사이트가 보여주고 `@dsh-fish/hub` 플러그인이 실행하는 것과 같은 설치 계획을 적용합니다. 쓰기는 모두 DeepSeek Harness의 `$DSH_HOME`에 이루어집니다.

## 아티팩트 설치

```sh
npx @dsh-fish/cli add release-notes
npx @dsh-fish/cli add https://dsh.fish/a/release-notes --profile web
npx @dsh-fish/cli add acme/notes
```

`add`는 Hub id, dsh.fish URL 또는 `owner/repo`를 카탈로그의 아티팩트로 해석한 뒤 계획을 실행합니다.

- `$DSH_HOME` 아래에 파일을 씁니다
- 패키지 매니저로 패키지를 추가합니다

소스에서 빌드하는 git 패키지는 `--allow-build-scripts`를 전달하기 전까지 거부됩니다. 이 플래그는 해당 패키지의 `prepare` 스크립트를 이 머신, 에이전트 샌드박스 밖에서 실행하도록 허용하는 것입니다.

`--yes`는 확인 프롬프트를 건너뛸 뿐 이 권한을 주지 않습니다.

## 기타 명령

| 명령                               | 기능                                                              |
| ---------------------------------- | ----------------------------------------------------------------- |
| `find [query]`                     | 카탈로그를 검색합니다(`--kind`로 유형 하나로 제한).               |
| `show <source>`                    | 아티팩트 하나와 설치가 실행할 명령을 보여줍니다.                  |
| `list`                             | 이 머신이 CLI 또는 hub 플러그인으로 설치한 아티팩트를 나열합니다. |
| `remove <id>`                      | 기록된 파일, 패치 행, 패키지를 되돌립니다.                        |
| `update [id]`                      | 현재 계획을 다시 적용합니다.                                      |
| `init [name]`                      | hub 인덱서가 받아들이는 `SKILL.md`를 작성합니다.                  |
| `login` / `logout` / `whoami`      | 기기 로그인 계정. hub 플러그인과 같은 토큰을 씁니다.              |
| `rate <source> <1-5> [comment...]` | 아티팩트를 평가. 이전 평가를 덮어씁니다. `login` 필요.            |
| `reviews <source>`                 | 평균 평점, 5에서 1까지의 분포, 최근 댓글.                         |

```sh
npx @dsh-fish/cli find postgres --kind bundle
npx @dsh-fish/cli list --json
npx @dsh-fish/cli remove release-notes
npx @dsh-fish/cli init my-skill
npx @dsh-fish/cli rate dsh-postgres-mcp 5 "installed and queried in minutes"
```

## 평가

사이트는 1–5점 척도를 씁니다. 1점은 동작하지 않거나 오해를 부르는 경우, 5점은 뛰어난 경우입니다. `reviews`는 익명입니다. `rate`는 `login`이 필요하고 항상 로그인한 계정의 이름으로 기록됩니다. 다시 평가하면 이전 평가를 덮어씁니다.

이 CLI를 구동하는 에이전트는 hub 플러그인의 `hub_rate` 도구가 명시한 것과 같은 규칙을 따라야 합니다. 실제로 설치하고 사용한 것만 직접 확인한 근거로 평가하고, 평가를 남길 때 사용자에게 알립니다.

## 옵션

| 옵션                    | 설명                                                              |
| ----------------------- | ----------------------------------------------------------------- |
| `--profile, -p`         | 하니스 프로필(기본값 `$DSH_PROFILE` 또는 `web`).                  |
| `--registry`            | Hub 오리진(기본값 `$DSH_FISH_URL` 또는 `https://dsh.fish`).       |
| `--kind, -k`            | `find`를 아티팩트 유형 하나로 제한합니다.                         |
| `--allow-build-scripts` | git 패키지가 prepare 스크립트를 실행하도록 허용합니다.            |
| `--json`                | 기계 판독용 출력.                                                 |
| `--yes, -y`             | 확인 프롬프트를 건너뜁니다. 빌드 스크립트는 허용하지 않습니다.  |
