在应用对话框里输入文本即可得到一段视频。哪怕只是简单的一句话，也会自动扩展为详细的视频提示词再生成。

本文将介绍如何体验文生视频，以及如何自己搭建 AI 视频生成应用。

- 图片视频生成一条龙：[https://udify.app/chat/18qSv1wysmRTsw34](https://udify.app/chat/18qSv1wysmRTsw34)
- 文生视频：[https://udify.app/chat/y3eBFyaxNJkXDlca](https://udify.app/chat/y3eBFyaxNJkXDlca)

示例效果包括：女孩与狐狸（文生视频）、千军万马来相见（文生视频）、王与飞机（图生视频）、古代战马（图生视频）。

不需要复杂注册认证。发挥想象力即可。

## 实现原理

这三个应用都是在 Dify 里搭的，核心是 Dify 的视频生成插件。

如果你还不了解 Dify，可以把它理解成一个 AI 应用游乐场，像拼乐高一样搭应用。官网：[https://dify.ai/](https://dify.ai/)

下面是完整复刻步骤。大约三分钟。

### 1. 注册并登录 Dify

打开 [https://cloud.dify.ai/](https://cloud.dify.ai/)，用邮箱注册。右上角可切语言。也可以安装开源社区版。

### 2. 安装视频插件并完成授权

Dify 本身不是视频模型。生成视频靠外部插件。

右上角「插件」→「探索 Marketplace」，搜索视频，找到 **Doubao Image and Video Generator**。能力基于豆包。安装后填写你自己的 API Key 完成授权，不要把密钥写进文档或提交到仓库。

### 3. 创建应用

注册进平台之后还要创建一个应用，再往里加视频生成。

#### 3.1 复制现成应用

Dify 应用底层是 DSL。在网页里「导入 DSL 文件」，粘贴链接即可：

- 文本生成视频：[https://r2.xmsex.net/2025/06/07cd66a9979953c29475dd34dd8663bf.yml](https://r2.xmsex.net/2025/06/07cd66a9979953c29475dd34dd8663bf.yml)
- 图片视频生成一条龙：[https://r2.xmsex.net/2025/06/3334f9aed0fd9dbe00b1872bf931184c.yml](https://r2.xmsex.net/2025/06/3334f9aed0fd9dbe00b1872bf931184c.yml)
- 图片生成视频：[https://r2.xmsex.net/2025/06/6b76198e75d363debeb065bc74f1160d.yml](https://r2.xmsex.net/2025/06/6b76198e75d363debeb065bc74f1160d.yml)

#### 3.2 从零搭建

创建空白应用，选 Chatflow，填名称和描述。

添加工具节点，选 Doubao Generator。按你要的效果选文生图、文生视频或图生视频。

每个工具节点都有默认输入输出。文生视频的输入是提示词，输出是插件生成的视频。

我把输入接到上一步 LLM 的输出：用户的提示词往往不够细，先让模型扩写成详细视频提示词，再送给生成节点。这个插件也可以用在 Agent 节点里。

如果还没搞懂工作流，先看：[Dify Workflow](https://docs.dify.ai/zh-hans/guides/workflow/readme)。

## 总结

以前在 Dify 里生成视频，多半是 HTTP 节点去打外部 API。能跑，但不优雅，每个想做视频的人都要重配一遍。这是个普遍需求，不如做成插件，填 API Key 就能用。
