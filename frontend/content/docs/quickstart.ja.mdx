## 1. Web UI を起動する

```sh
npx @deepseek-ai/dsh web
```

ブラウザが開かなければ `http://127.0.0.1:3080` にアクセスします。

## 2. モデルを接続する

**Settings → Models** を開き、プロバイダー、モデル名、API キーを入力して保存します。次のリクエストから反映され、再起動は不要です。OpenAI 互換エンドポイントでは base URL とモデル識別子を正確に確認してください。

## 3. ワークスペースを選ぶ

**Choose workspace** から対象リポジトリを選びます。ワークスペースは信頼境界です。無関係な秘密情報や個人ファイルを含む上位ディレクトリは開かないでください。

## 4. 最初のタスク

```text
Summarize this repository and identify its main packages.
```

回答に出たファイルが実在することを確かめ、次に小さなテストを一つ実行します。権限要求と差分を個別に確認してください。`workspace-write` は書き込みを制御しますが、すべての読み取り、プロセス、ネットワークを隔離するものではありません。

次は [Hub プラグイン](/docs/hub)を導入するか、[最初のプラグイン](/docs/develop/first-plugin)を作ります。
