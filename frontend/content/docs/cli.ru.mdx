`@dsh-fish/cli` устанавливает артефакты [dsh.fish](https://dsh.fish) из терминала. Команда установки на странице артефакта — это этот бинарник: он применяет тот же план установки, который показывает сайт и выполняет плагин `@dsh-fish/hub`. Всё записывается в `$DSH_HOME` DeepSeek Harness.

## Установка артефакта

```sh
npx @dsh-fish/cli add release-notes
npx @dsh-fish/cli add https://dsh.fish/a/release-notes --profile web
npx @dsh-fish/cli add acme/notes
```

`add` разрешает Hub id, URL dsh.fish или `owner/repo` в артефакт из каталога, затем выполняет план:

- файлы в `$DSH_HOME`
- добавление пакетов пакетным менеджером

Git-пакеты, собираемые из исходников, отклоняются, пока вы не передадите `--allow-build-scripts`. Этот флаг разрешает запуск скрипта `prepare` пакета на этой машине, вне песочницы агента.

`--yes` лишь пропускает вопросы подтверждения и такого разрешения не даёт.

## Остальные команды

| Команда                            | Что делает                                                            |
| ---------------------------------- | --------------------------------------------------------------------- |
| `find [query]`                     | Ищет по каталогу (`--kind` ограничивает одним типом).                 |
| `show <source>`                    | Один артефакт и команды, которые выполнит его установка.              |
| `list`                             | Артефакты, установленные этой машиной через CLI или плагин hub.       |
| `remove <id>`                      | Откатывает записанные файлы, строки патча и пакеты.                   |
| `update [id]`                      | Заново применяет текущий план.                                        |
| `init [name]`                      | Пишет `SKILL.md`, который примет индексатор hub.                      |
| `login` / `logout` / `whoami`      | Учётная запись с входом с устройства, тот же токен, что у плагина hub. |
| `rate <source> <1-5> [comment...]` | Оценить артефакт; заменяет вашу прежнюю оценку. Нужен `login`.        |
| `reviews <source>`                 | Средняя оценка, распределение от 5 до 1 и свежие комментарии.         |

```sh
npx @dsh-fish/cli find postgres --kind bundle
npx @dsh-fish/cli list --json
npx @dsh-fish/cli remove release-notes
npx @dsh-fish/cli init my-skill
npx @dsh-fish/cli rate dsh-postgres-mcp 5 "installed and queried in minutes"
```

## Оценки

На сайте шкала от 1 до 5 звёзд: 1 — не работает или вводит в заблуждение, 5 — отлично. `reviews` работает анонимно; `rate` требует `login` и всегда записывается от имени вошедшей учётной записи. Повторная оценка заменяет прежнюю.

Агент, управляющий этим CLI, должен следовать тому же правилу, что указано в инструменте `hub_rate` плагина hub: оценивать только то, что он действительно установил и использовал, опираться на собственный опыт и сообщать пользователю, когда оставляет оценку.

## Опции

| Опция                   | Описание                                                              |
| ----------------------- | --------------------------------------------------------------------- |
| `--profile, -p`         | Профиль harness (по умолчанию `$DSH_PROFILE` или `web`).              |
| `--registry`            | Источник hub (по умолчанию `$DSH_FISH_URL` или `https://dsh.fish`).   |
| `--kind, -k`            | Ограничивает `find` одним типом артефактов.                           |
| `--allow-build-scripts` | Разрешает git-пакету запустить его prepare-скрипт.                    |
| `--json`                | Машиночитаемый вывод.                                                 |
| `--yes, -y`             | Пропускает вопросы подтверждения. Сборочные скрипты не разрешает.     |
