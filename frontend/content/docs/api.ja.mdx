---
title: REST API
description: 公開 JSON API で dsh.fish を検索し、成果物と導入計画を確認し、スコアとカタログを同期します。
---

公開 API は検索と読み取り専用のカタログ連携に使います。完全な仕様は [OpenAPI 文書](/openapi.json)にあります。

```sh
curl -s 'https://dsh.fish/api/v1/artifacts?q=postgres&kind=mcp-server'
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/install-plan?profile=web'
curl -s 'https://dsh.fish/api/v1/scoring'
```

導入計画はデータです。盲目的に実行せず、各ファイル、パッケージ、profile patch を利用者に示し、ビルドスクリプトは別に確認してください。

`/api/v1/catalog/version` を先に確認し、`dataVersion` が変わったときだけ snapshot を取得して `ETag` を保存します。公開読み取りにアカウントは不要です。
