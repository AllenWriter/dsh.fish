## 1. Start the Web UI

```sh
npx @deepseek-ai/dsh web
```

Open `http://127.0.0.1:3080` if the browser does not open automatically. The package is a developer preview, so read the npm prompt and release notes before using it on important work.

## 2. Connect a model

Open **Settings → Models**, choose a provider, enter the model name and API key, then save. The next request uses the saved configuration; no restart is needed.

For an OpenAI-compatible endpoint, check the provider's base URL and model identifier exactly. A successful credential save does not prove that the endpoint accepts the selected model, so run the small first task below before a long session.

## 3. Choose a workspace

Select **Choose workspace** and open the repository you want the agent to inspect. The composer remains unavailable until a workspace is selected. Treat the workspace as a trust boundary: review the repository first, and do not open a directory containing unrelated secrets.

## 4. Run a first task

Send a read-only request:

```text
Summarize this repository and identify its main packages.
```

Check that the response names files that actually exist. Then ask for a small, verifiable action such as running one test target. Review each requested permission and the resulting diff.

## Understand permissions

A new session normally starts with `workspace-write`. This controls writes, but it does not mean every process, read, or network action is isolated. Approve only the operation you understand, keep credentials outside the workspace, and inspect changes before committing.
