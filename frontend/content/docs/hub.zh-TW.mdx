```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

Git 安裝會執行 `prepare`。pnpm 10 以上版本可能要求在 profile 的 `pnpm-workspace.yaml` 明確允許 `dsh-hub` 建置。該指令碼在代理沙箱之外執行，請固定 commit 後再授權。

核心工具為 `hub_search`、`hub_show`、`hub_install`、`hub_list`、`hub_update` 和 `hub_remove`。先用 `hub_show` 檢視完整計畫。成功安裝會記錄在 `$DSH_HOME/.dsh-fish-lock.json`，並與 CLI 共用。

讀取目錄不需登入。`hub_account` 使用裝置授權流程；token 儲存在 `$DSH_HOME/.dsh-fish-token.json`，不會寫入記錄。裝置 token 可以評分，但不能提交或認領製品。
