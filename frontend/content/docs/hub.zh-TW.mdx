Hub 外掛程式（`dsh-hub`）把 dsh.fish 目錄帶進正在執行的工作階段。代理可以搜尋構件、告訴你安裝會執行什麼，並在你同意後完成安裝。你不需要離開工作階段。

## 新增外掛程式

```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

這個套件是 TypeScript 寫的，從 git 安裝會執行它的 `prepare` 指令碼來建置 `lib/`。pnpm 10 以上版本預設拒絕，需要你明確允許。把 pnpm 印出的套件名稱複製到配置檔案的 `pnpm-workspace.yaml` 裡：

```yaml
allowBuilds:
  dsh-hub: true
```

然後重新執行 `add`。

這項允許意味著該套件的程式碼會在安裝時執行在你的機器上，處於代理沙箱之外。請固定 commit，避免之後的推送改變要執行的內容。

## 查找

`hub_search` 按自由文字搜尋目錄，也可以用 `kind` 參數限定一種構件類型。它回傳的 id 可以傳給其他 hub 工具。

讀取目錄不需要帳號。

## 安裝

`hub_install` 在這台機器上執行安裝計畫：

- 寫入 skill 和 preset 檔案
- 把 MCP 和 hook 列加入配置檔案的補丁層
- 為 bundle 執行套件管理器

完成後重新啟動 harness，新設定才會載入。

如果計畫中有從原始碼建置的套件，`hub_install` 會拒絕執行，直到呼叫方傳入 `allowBuildScripts: true`。這一步會在安裝時把該套件的程式碼執行在你的機器上，處於代理沙箱之外，所以代理必須回來問你，不能自行授權。

安裝成功後記錄在 `$DSH_HOME/.dsh-fish-lock.json`：

- `hub_list` 列出這台機器已安裝的構件
- `hub_update` 為已安裝的構件重新執行目前計畫
- `hub_remove` 撤銷一次已記錄的安裝（檔案、補丁列、套件）

這個鎖定檔案與 `@dsh-fish/cli` 共用，所以 [CLI](/docs/cli) 看到的是同一份安裝記錄。

## 登入

登入後安裝會記到你的帳號下，並解鎖 `hub_rate`。讀取目錄不需要帳號。

`hub_account` 使用 `action: "login"` 發起一次 OAuth 裝置流程登入：

- 工具回傳一個短碼和一個 URL
- 你在瀏覽器裡開啟 URL 並批准
- 外掛程式會一直等待到你完成

代理無法替你批准。

token 寫入 `$DSH_HOME/.dsh-fish-token.json`，檔案權限為 0600，不會寫入記錄。

這個 token 刻意弱於瀏覽器工作階段。它能以你的身分讀取目錄、解析安裝計畫、給構件評分，但不能提交或認領構件。

## 安全

寫檔案的步驟被限制在解析後的 `$DSH_HOME` 內，試圖越界的計畫會被拒絕。

從原始碼建置的步驟需要你的明確同意，如上所述。

`hub_rate` 自帶一條規則：代理只給這台機器實際安裝並使用過的構件評分，依據第一手證據，並在評分時告知你。

## 工具

| 工具          | 作用                                                   |
| ------------- | ------------------------------------------------------ |
| `hub_search`  | 按文字和構件類型搜尋註冊表。                           |
| `hub_show`    | 展示一個構件的詳情，包括安裝會執行的內容。             |
| `hub_install` | 在這台機器上執行安裝計畫。                             |
| `hub_list`    | 列出這台機器透過 hub 安裝的構件。                      |
| `hub_remove`  | 撤銷一次已記錄的安裝（檔案、補丁列、套件）。           |
| `hub_update`  | 為已安裝的構件重新執行目前計畫。                       |
| `hub_account` | 透過 OAuth 裝置流程登入、查看狀態或登出。              |
| `hub_reviews` | 社群評分：站內 1–5 星制、平均分、分布和評論。          |
| `hub_rate`    | 給已安裝的構件打 1–5 星，可附公開評論。                |

## 設定

```yaml
- id: hub
  name: dsh-hub
  config:
    baseUrl: https://dsh.fish # 自架部署只需要改這一項
    targetProfile: current # 或者具體的配置檔案名
```
