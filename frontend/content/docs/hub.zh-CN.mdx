```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

Git 安装会运行 `prepare`。pnpm 10 及以上版本可能要求在 profile 的 `pnpm-workspace.yaml` 中明确允许 `dsh-hub` 构建。该脚本运行在智能体沙箱之外，请固定 commit 后再授权。

核心工具为 `hub_search`、`hub_show`、`hub_install`、`hub_list`、`hub_update` 和 `hub_remove`。先用 `hub_show` 查看完整计划，再决定是否安装。需要构建脚本时，插件必须返回并请求用户明确批准。

成功安装记录在 `$DSH_HOME/.dsh-fish-lock.json`，与 CLI 共用。文件写入被限制在解析后的 `$DSH_HOME` 内；试图越界的计划会被拒绝。

目录读取无需登录。`hub_account` 使用设备授权流程登录；令牌保存在 `$DSH_HOME/.dsh-fish-token.json`，不会写入日志。设备令牌可以评分，但不能提交或认领制品。
