| 用語 | 意味 |
| --- | --- |
| エージェントハーネス | AI エージェントを実行するプログラム。モデルをツールに接続し、エージェントに許可する動作を制御する。 |
| `$DSH_HOME` | Harness がすべてのユーザーデータを保存するルートディレクトリ。デフォルトは `~/.dsh`。 |
| プロファイル(profile) | `$DSH_HOME/profiles/<name>` 配下の名前付きセットアップ。どのプラグインを読み込むかを決める。 |
| セッション(session) | エージェントとの 1 回の会話。追加専用のイベントログとして保存される。 |
| ワークスペース(workspace) | エージェントに渡すプロジェクトディレクトリ。エージェントが書き込める範囲を限定する。 |
| モデル / プロバイダー | エージェントが思考に使う AI と、それを提供するサービス。API キーは自分のマシンに保存される。 |
| 権限(permissions) | エージェントに許可する動作を制御するプリセット。デフォルトは `workspace-write`。 |
| プラグイン(plugin) | 唯一の拡張単位。組み込みでも後からインストールしたものでも、すべての機能はプラグイン。 |

各用語の説明の最後に、実際に使うページへのリンクを付けています。

## エージェントハーネス

エージェントハーネスは、AI モデルをエージェントに変えるプログラムです。モデルにツールを与え、結果を次のステップのためにモデルへ戻し、エージェントに許可する動作を制限します。

DeepSeek Harness は DeepSeek AI のオープンソースハーネスで、すべての機能がプラグインになるよう設計されています。

使用箇所: [クイックスタート](/docs/quickstart)。

## `$DSH_HOME`

Harness はすべてのユーザーデータ(プロファイル、設定、認証情報、セッションログ)を 1 つのルートディレクトリに保存します。環境変数 `$DSH_HOME` が設定されていればそれを、なければ `~/.dsh` を使います。

dsh.fish のインストールプランは、このルートかその中のプロファイルディレクトリにのみ書き込みます。

使用箇所: [Hub プラグイン](/docs/hub)と [CLI](/docs/cli) からのインストール。

## プロファイル(profile)

プロファイルは `$DSH_HOME/profiles/<name>` 配下のディレクトリで、1 つの Harness セットアップを定義するプラグインパッケージとパッチファイルを保持します。起動時に `--profile <name>` で選択します。`web` と `headless` のプロファイルは初回使用時に自動作成されます。

dsh.fish はすべてのプラグインを指定されたプロファイルにインストールします。

使用箇所: [CLI でのインストール](/docs/cli)。公開方法は [profile 形式](/docs/publish/profile)を参照してください。

## セッション(session)

セッションは、あなたとエージェントの間の 1 回の会話です。Harness はセッションを追加専用のイベントログ(メッセージ、ツール呼び出し、承認)として保存し、モデルが見る内容はそのログから導かれるため、セッションは再生・再開できます。

セッションはワークスペースごとにグループ化されます。

使用箇所: セッション内で動作する [Hub プラグイン](/docs/hub)。

## ワークスペース(workspace)

ワークスペースは、Harness に明示的に渡すプロジェクトディレクトリです。選択するまで Web UI の入力欄はロックされたままで、選択後はすべてのセッションがそのディレクトリを作業ディレクトリとして実行されます。

ワークスペースは信頼境界として扱ってください。デフォルトの権限ではエージェントはその配下のどこにでも書き込めるため、確認済みのディレクトリを選びます。

使用箇所: [クイックスタート](/docs/quickstart)のステップ 3。

## モデルとプロバイダー

モデルはエージェントが思考に使う AI で、プロバイダーはモデルを提供するサービスです。DeepSeek のほか、自分で追加したプロバイダーも使えます。**Settings → Models** でプロバイダーの API キーを一度入力します。

キーはローカルの `$DSH_HOME/.credentials.yaml` に保存され、dsh.fish に送信されることはありません。

使用箇所: [クイックスタート](/docs/quickstart)のステップ 2。

## 権限(permissions)

権限は、エージェントがツールで何をできるかを決めます。

権限は名前付きプリセットとして提供され、デフォルトの `workspace-write` は書き込みをワークスペース内(と一時領域)に限定し、承認が必要な操作の前に確認を求めます。`danger-full-access` はサンドボックスを外し、確認もしません。

使用箇所: [クイックスタート](/docs/quickstart)の権限に関する注記。

## プラグイン(plugin)

プラグインは Harness 唯一の拡張機構です。コアは意図的に小さく保たれ、ツール、モデルプロバイダー、承認ルールはすべてプラグインとして読み込まれ、プロファイルに列挙されます。

インストールしたプラグインは、あなたが Harness に与えた権限で動作します。だから dsh.fish では、インストール前にプラグインが何であり何をするかを確認できます。

使用箇所: [プラグインについて](/docs/plugins)と[最初のプラグイン](/docs/develop/first-plugin)。
