Hub 플러그인(`dsh-hub`)은 dsh.fish 카탈로그를 실행 중인 세션 안으로 가져옵니다. 에이전트가 아티팩트를 검색하고, 설치 시 무엇이 실행되는지 보여주고, 당신이 동의하면 설치합니다. 세션을 떠날 필요가 없습니다.

## 플러그인 추가

```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

이 패키지는 TypeScript이므로 git 설치 시 `lib/`를 빌드하는 `prepare` 스크립트가 실행됩니다. pnpm 10 이상은 허용하기 전까지 이를 거부합니다. pnpm이 출력하는 패키지 키를 프로필의 `pnpm-workspace.yaml`에 복사하세요.

```yaml
allowBuilds:
  dsh-hub: true
```

그런 다음 `add`를 다시 실행하세요. 이 허용은 패키지 자체 코드가 설치 시점에 에이전트 샌드박스 밖인 이 머신에서 실행되도록 하는 것입니다. 이후 푸시가 실행 내용을 바꾸지 못하도록 commit을 고정하세요.

## 찾기

`hub_search`는 자유 텍스트로 카탈로그를 검색하고, `kind` 인자로 아티팩트 유형 하나로 좁힐 수 있습니다. 반환된 id는 다른 hub 도구에 전달하면 됩니다. 카탈로그를 읽는 데는 계정이 필요 없습니다.

## 검토하기

## 설치

`hub_install`은 이 머신에서 설치 계획을 실행합니다. skill과 preset 파일을 쓰고, MCP와 hook 행을 프로필 패치 계층에 추가하고, 번들에는 패키지 매니저를 실행합니다. 끝나면 하니스를 재시작해야 새 행이 로드됩니다.

소스에서 빌드하는 패키지가 포함된 계획은 호출자가 `allowBuildScripts: true`를 전달하기 전까지 `hub_install`이 거부합니다. 이 단계는 패키지 코드를 설치 시점에 이 머신, 에이전트 샌드박스 밖에서 실행하므로 에이전트는 당신에게 다시 물어봐야 하며 스스로 허용할 수 없습니다.

성공한 설치는 `$DSH_HOME/.dsh-fish-lock.json`에 기록됩니다. `hub_list`는 이 머신이 설치한 것을 보여주고, `hub_update`는 설치된 아티팩트의 현재 계획을 다시 적용하며, `hub_remove`는 기록된 설치(파일, 패치 행, 패키지)를 되돌립니다. 이 잠금 파일은 `@dsh-fish/cli`와 공유되므로 [CLI](/docs/cli)도 같은 설치를 봅니다.

## 로그인

로그인하면 설치가 내 계정에 귀속되고 `hub_rate`를 쓸 수 있습니다. 카탈로그 읽기에는 계정이 필요 없습니다.

`hub_account`에 `action: "login"`을 주면 OAuth 기기 흐름이 시작됩니다. 도구가 짧은 코드와 URL을 반환하면 브라우저에서 URL을 열어 승인하세요. 플러그인은 승인될 때까지 폴합니다. 에이전트가 대신 승인할 수는 없습니다. 토큰은 `$DSH_HOME/.dsh-fish-token.json`에 파일 모드 0600으로 기록되며 로그에 남지 않습니다.

이 토큰은 일부러 브라우저 세션보다 약합니다. 당신으로서 카탈로그 읽기, 설치 계획 해석, 아티팩트 평가는 할 수 있지만 제출이나 소유권 신청은 할 수 없습니다.

## 안전

파일 쓰기 단계는 해석된 `$DSH_HOME` 안으로 제한되며, 벗어나려는 계획은 거부됩니다. 소스 빌드 단계에는 위에서 설명한 명시적 동의가 필요합니다. `hub_rate`에는 자체 규칙이 있습니다. 에이전트는 이 머신에서 실제로 설치해 사용한 것만 직접 확인한 근거로 평가하고, 평가를 남길 때 당신에게 알립니다.

## 도구

| 도구          | 기능                                                              |
| ------------- | ----------------------------------------------------------------- |
| `hub_search`  | 텍스트와 아티팩트 유형으로 레지스트리를 검색합니다.               |
| `hub_show`    | 아티팩트 하나의 상세 정보와 설치가 실행할 내용을 보여줍니다.      |
| `hub_install` | 이 머신에서 설치 계획을 실행합니다.                               |
| `hub_list`    | 이 머신이 hub를 통해 설치한 아티팩트를 나열합니다.                |
| `hub_remove`  | 기록된 설치(파일, 패치 행, 패키지)를 되돌립니다.                  |
| `hub_update`  | 설치된 아티팩트의 현재 계획을 다시 적용합니다.                    |
| `hub_account` | OAuth 기기 흐름으로 로그인, 상태 확인, 로그아웃을 합니다.         |
| `hub_reviews` | 커뮤니티 평가: 사이트의 1–5점 척도, 평균, 분포, 댓글.             |
| `hub_rate`    | 설치된 아티팩트를 1–5점으로 평가. 공개 댓글을 달 수 있습니다.     |

## 설정

```yaml
- id: hub
  name: dsh-hub
  config:
    baseUrl: https://dsh.fish # 셀프 호스팅 배포는 이 항목만 바꾸면 됩니다
    targetProfile: current # 또는 구체적인 프로필 이름
```
