Hub 플러그인(`@dsh-fish/hub`)은 dsh.fish 카탈로그를 실행 중인 세션 안으로 가져옵니다. 에이전트가 아티팩트를 검색하고, 설치 시 무엇이 실행되는지 보여주고, 당신이 동의하면 설치합니다. 세션을 떠날 필요가 없습니다.

## 플러그인 추가

```sh
dsh plugin --profile <profile> add @dsh-fish/hub
```

`<profile>`은 하네스가 부팅하는 프로필입니다. 기본 런처는 `web`이고, 데스크톱 빌드는 자신이 시작하는 프로필을 씁니다. npm에 게시된 패키지에는 빌드된 `lib/`가 들어 있으므로 이 설치는 빌드 스크립트를 실행하지 않고 `allowBuilds` 항목도 필요하지 않습니다.

### Local DSH

[Local DSH](https://github.com/stvlynn/local-dsh)는 `local-dsh`로 부팅하며, 그 런처는 전역 `PATH`가 아니라 앱에 포함된 런타임 안에 있습니다. 앱이 실제로 시작하는 프로필에 설치되도록 그 런처를 사용하세요.

```sh
APP_DATA="$HOME/Library/Application Support/com.localdsh.app"
RUNTIME="$(find "$APP_DATA/runtime" -maxdepth 1 -type d ! -name runtime ! -name '.partial-*' | head -n 1)"
export PATH="$RUNTIME/bin:$PATH"

dsh plugin --profile local-dsh add @dsh-fish/hub
```

그런 다음 DSH를 재시작하세요. 플러그인의 도구는 부팅 시 로드됩니다. 앱은 시작할 때마다 자신이 관리하는 번들 목록을 다시 쓰지만 당신이 추가한 번들은 유지하므로, 재시작 후에도 플러그인은 남아 있습니다.

### git에서 설치

git 설치는 개발용 대안이며 하위 디렉터리를 지정해야 합니다. 저장소 루트는 private workspace이고 이 플러그인이 아닙니다.

```sh
dsh plugin --profile <profile> add github:stvlynn/dsh.fish#path:packages/dsh-plugin-hub
```

이 체크아웃에는 `lib/`가 없어 설치 시 빌드가 실행되며, pnpm 10 이상은 허용하기 전까지 빌드 스크립트를 거부합니다. pnpm이 출력하는 패키지 키를 프로필의 `pnpm-workspace.yaml`에 복사한 뒤 `add`를 다시 실행하세요. 이 허용은 패키지 자체 코드가 설치 시점에 에이전트 샌드박스 밖인 이 머신에서 실행되도록 하는 것입니다. 이후 푸시가 실행 내용을 바꾸지 못하도록 commit을 고정하세요.

### `dsh-hub`에서 이전

이전 버전은 `dsh-hub`라는 이름으로 저장소 루트에서 설치했습니다.

```sh
dsh plugin --profile <profile> remove dsh-hub
dsh plugin --profile <profile> add @dsh-fish/hub
```

`$DSH_HOME/.dsh-fish-lock.json`에 이미 기록된 설치는 이름 변경에 영향받지 않습니다.

## 설치

`hub_install`은 이 머신에서 설치 계획을 실행합니다.

- skill과 preset 파일을 씁니다
- 번들에는 패키지 매니저를 실행합니다

끝나면 하니스를 재시작해야 새 행이 로드됩니다.

소스에서 빌드하는 패키지가 포함된 계획은 호출자가 `allowBuildScripts: true`를 전달하기 전까지 `hub_install`이 거부합니다. 이 단계는 패키지 코드를 설치 시점에 이 머신, 에이전트 샌드박스 밖에서 실행하므로 에이전트는 당신에게 다시 물어봐야 하며 스스로 허용할 수 없습니다.

성공한 설치는 `$DSH_HOME/.dsh-fish-lock.json`에 기록됩니다.

- `hub_list`는 이 머신이 설치한 것을 보여줍니다
- `hub_update`는 설치된 아티팩트의 현재 계획을 다시 적용합니다
- `hub_remove`는 기록된 설치(파일, 패치 행, 패키지)를 되돌립니다

이 잠금 파일은 `@dsh-fish/cli`와 공유되므로 [CLI](/docs/cli)도 같은 설치를 봅니다.

## 로그인

로그인하면 설치가 내 계정에 귀속되고 `hub_rate`를 쓸 수 있습니다. 카탈로그 읽기에는 계정이 필요 없습니다.

`hub_account`에 `action: "login"`을 주면 OAuth 기기 흐름이 시작됩니다.

- 도구가 짧은 코드와 URL을 반환합니다
- 브라우저에서 URL을 열어 승인하세요
- 플러그인은 승인될 때까지 폴합니다

에이전트가 대신 승인할 수는 없습니다.

토큰은 `$DSH_HOME/.dsh-fish-token.json`에 파일 모드 0600으로 기록되며 로그에 남지 않습니다.

이 토큰은 일부러 브라우저 세션보다 약합니다. 당신으로서 카탈로그 읽기, 설치 계획 해석, 아티팩트 평가는 할 수 있지만 제출이나 소유권 신청은 할 수 없습니다.

## 설정의 섹션

브라우저 클라이언트를 제공하는 하네스에서는 이 플러그인이 설정에 **dsh.fish** 섹션을 추가하며, 탭이 세 개 있습니다.

- **Browse**: 카탈로그를 검색하고, 무엇이든 실행하기 전에 아티팩트의 설치 계획을 보여줍니다. 소스에서 빌드하는 패키지는 그 사실을 명시한 버튼을 누를 때까지 거부됩니다.
- **Installed**: 이 프로필이 허브를 통해 설치한 것을 나열하고 거기서 제거할 수도 있습니다.
- **Account**: 같은 디바이스 플로우로 로그인하며, 코드와 검증 URL을 일반 링크로 보여줍니다.

이는 같은 설치기에 대한 두 번째 화면이지 두 번째 설치기가 아닙니다. 이 섹션이 호출하는 동일 출처 라우트는 `hub_*` 도구가 실행하는 바로 그 코드를 실행하고, 같은 `$DSH_HOME/.dsh-fish-lock.json`에 씁니다. 따라서 Installed 목록은 `hub_list`가 보고하는 것과 정확히 같습니다.

계정과 관련된 것은 브라우저로 넘어가지 않습니다. 디바이스 코드와 저장된 토큰은 호스트 쪽에 남으며, 그래서 데스크톱 앱이 검증 링크를 앱 창 안이 아니라 시스템 브라우저로 넘길 수 있습니다.

브라우저 클라이언트를 제공하지 않는 프로필에서도 도구는 로드됩니다.

## 안전

파일 쓰기 단계는 해석된 `$DSH_HOME` 안으로 제한되며, 벗어나려는 계획은 거부됩니다.

소스 빌드 단계에는 위에서 설명한 명시적 동의가 필요합니다.

`hub_rate`에는 자체 규칙이 있습니다. 에이전트는 이 머신에서 실제로 설치해 사용한 것만 직접 확인한 근거로 평가하고, 평가를 남길 때 당신에게 알립니다.

## 도구

| 도구          | 기능                                                              |
| ------------- | ----------------------------------------------------------------- |
| `hub_search`  | 텍스트와 아티팩트 유형으로 레지스트리를 검색합니다.               |
| `hub_show`    | 아티팩트 하나의 상세 정보와 설치가 실행할 내용을 보여줍니다.      |
| `hub_install` | 이 머신에서 설치 계획을 실행합니다.                               |
| `hub_list`    | 이 머신이 hub를 통해 설치한 아티팩트를 나열합니다.                |
| `hub_remove`  | 기록된 설치(파일, 패치 행, 패키지)를 되돌립니다.                  |
| `hub_update`  | 설치된 아티팩트의 현재 계획을 다시 적용합니다.                    |
| `hub_account` | OAuth 기기 흐름으로 로그인, 상태 확인, 로그아웃을 합니다.         |
| `hub_reviews` | 커뮤니티 평가: 사이트의 1–5점 척도, 평균, 분포, 댓글.             |
| `hub_rate`    | 설치된 아티팩트를 1–5점으로 평가. 공개 댓글을 달 수 있습니다.     |

## 설정

```yaml
- id: hub
  name: '@dsh-fish/hub'
  config:
    baseUrl: https://dsh.fish # 셀프 호스팅 배포는 이 항목만 바꾸면 됩니다
    targetProfile: current # 또는 구체적인 프로필 이름
```
