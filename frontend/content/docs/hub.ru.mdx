```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

Установка из Git запускает `prepare`. В pnpm 10+ может потребоваться разрешить сборку `dsh-hub` в `pnpm-workspace.yaml` profile. Скрипт выполняется вне песочницы: закрепите commit до выдачи разрешения.

Главные инструменты: `hub_search`, `hub_show`, `hub_install`, `hub_list`, `hub_update`, `hub_remove`. Сначала откройте полный план через `hub_show`. Установки записываются в общий с CLI файл `$DSH_HOME/.dsh-fish-lock.json`.

Чтение каталога не требует входа. Токен устройства позволяет оценивать, но не публиковать и не заявлять права на артефакт.
