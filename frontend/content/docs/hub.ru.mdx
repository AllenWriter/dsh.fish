Плагин Hub (`dsh-hub`) переносит каталог dsh.fish в работающий сеанс. Агент может найти артефакт, показать, что именно сделает установка, и установить его после вашего согласия. Покидать сеанс не нужно.

## Добавьте плагин

```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

Пакет написан на TypeScript, поэтому при установке из git запускается его скрипт `prepare`, собирающий `lib/`. pnpm 10 и новее отказывается это делать, пока вы не разрешите. Скопируйте ключ пакета, который выводит pnpm, в `pnpm-workspace.yaml` вашего профиля:

```yaml
allowBuilds:
  dsh-hub: true
```

Затем повторите `add`.

Это разрешение позволяет коду пакета выполняться на вашей машине во время установки, вне песочницы агента. Закрепите commit, чтобы более поздний push не изменил то, что будет запущено.

## Поиск

`hub_search` ищет по каталогу свободным текстом, а аргумент `kind` сужает выдачу до одного типа артефактов. Возвращаемые id передаются другим инструментам hub.

Чтение каталога не требует учётной записи.

## Проверка

`hub_show` показывает один артефакт подробно, включая точные команды, которые установка выполнит на этой машине. `hub_reviews` анонимно читает оценки сообщества: средний балл по шкале 1–5, распределение и свежие комментарии.

Проверьте оба инструмента, прежде чем разрешить агенту установку. Те же доказательства видны на сайте, если хотите сверить там.

## Установка

`hub_install` применяет план установки на этой машине:

- записывает файлы skill и preset
- добавляет строки MCP и hook в патч-слой профиля
- запускает пакетный менеджер для бандлов

После этого перезапустите harness, чтобы новые строки загрузились.

Если шаг плана собирает пакет из исходников, `hub_install` отказывает, пока вызывающая сторона не передаст `allowBuildScripts: true`. Такой шаг запускает код пакета на вашей машине во время установки, вне песочницы агента, поэтому агент обязан вернуться и спросить вас. Сам он это разрешить не может.

Успешные установки записываются в `$DSH_HOME/.dsh-fish-lock.json`:

- `hub_list` показывает, что установлено на этой машине
- `hub_update` заново применяет текущий план для установленного артефакта
- `hub_remove` откатывает записанную установку (файлы, строки патча, пакеты)

Файл блокировки общий с `@dsh-fish/cli`, поэтому [CLI](/docs/cli) видит те же установки.

## Вход

Вход привязывает установки к вашей учётной записи и открывает `hub_rate`. Чтение каталога не требует входа.

`hub_account` с `action: "login"` начинает OAuth device flow:

- инструмент возвращает короткий код и URL
- вы открываете URL в браузере и подтверждаете вход
- плагин опрашивает сервер, пока вы это делаете

Агент не может подтвердить вход за вас.

Токен записывается в `$DSH_HOME/.dsh-fish-token.json` с правами 0600 и не попадает в логи.

Этот токен намеренно слабее браузерной сессии. Он может читать каталог, разрешать планы установки и оценивать артефакты от вашего имени, но не может публиковать артефакты и заявлять права на них.

## Безопасность

Запись файлов ограничена разрешённым `$DSH_HOME`; план, пытающийся выйти за его пределы, отклоняется.

Шаги со сборкой из исходников требуют вашего явного согласия, как описано выше.

У `hub_rate` есть собственное правило: агент оценивает только то, что эта машина действительно установила и использовала, опирается на собственный опыт и сообщает вам, когда оставляет оценку.

## Инструменты

| Инструмент    | Что делает                                                                 |
| ------------- | -------------------------------------------------------------------------- |
| `hub_search`  | Ищет в реестре по тексту и типу артефакта.                                 |
| `hub_show`    | Показывает один артефакт подробно, включая то, что сделает установка.      |
| `hub_install` | Применяет план установки на этой машине.                                   |
| `hub_list`    | Артефакты, которые эта машина установила через hub.                        |
| `hub_remove`  | Откатывает записанную установку (файлы, строки патча, пакеты).             |
| `hub_update`  | Заново применяет текущий план для установленного артефакта.                |
| `hub_account` | Вход через OAuth device flow, проверка статуса, выход.                     |
| `hub_reviews` | Оценки сообщества: шкала 1–5, средний балл, распределение, комментарии.    |
| `hub_rate`    | Оценить установленный артефакт на 1–5 звёзд, можно с публичным отзывом.    |

## Конфигурация

```yaml
- id: hub
  name: dsh-hub
  config:
    baseUrl: https://dsh.fish # при самостоятельном развёртывании меняется только это
    targetProfile: current # или конкретное имя профиля
```
