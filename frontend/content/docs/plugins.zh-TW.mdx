DeepSeek Harness 運行在 Cordis 外掛框架之上。模型轉接器、工具註冊表、工作階段日誌和代理迴圈都是從設定掛載的外掛。

沒有需要修補的特權核心：要擴充 Harness，就把一個外掛掛載到其他外掛旁邊。外掛註冊的一切都會在卸載時被清理。

核心因此保持小巧。想要新能力時，你安裝一個外掛，而不是等待 Harness 升級。

## 外掛可以是什麼

dsh.fish 目錄收錄四種構件類型，各有自己的清單契約：

- [Bundle](/docs/publish/bundle)：向配置檔案新增一層外掛 patch 的 npm 套件。
- [Skill](/docs/publish/skill)：代理按需載入的 Markdown 指令檔案。
- [Agent preset](/docs/publish/agent-preset)：一個 `agent.cordis.yml`，讓某個工作階段擁有自己的工具和提示詞。
- [Profile](/docs/publish/profile)：構成完整組合的有序 bundle 堆疊。

## 信任問題

外掛是以你授予 Harness 的權限運行的程式碼。

它在你的工作區內行動。git 安裝還可能在代理沙箱之外執行套件的建置指令碼。

README 告訴你的是作者的宣告，不是安裝實際會做什麼。

dsh.fish 正是為這一缺口而存在。

目錄讀取每個來源真實的清單和檔案。每個構件頁面都在你執行任何命令之前展示安裝計畫（安裝將執行的檔案寫入和套件安裝）。

先檢查，再安裝。

要自己編寫外掛，從[開發第一個外掛程式](/docs/develop/first-plugin)開始。
