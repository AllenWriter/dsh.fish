DeepSeek Harness (`dsh`) is an open-source agent harness from DeepSeek AI: a program that runs an AI agent on your own machine. It connects a model you choose to tools that read and edit files and run commands, and it records everything the agent does.

You start it locally with `npx @deepseek-ai/dsh web`, which opens a Web UI.

dsh.fish is an independent catalog of extensions for the harness. It finds plugins, reads what they actually contain, and shows you an install plan before anything is written to your machine.

The website, the dsh.fish CLI, and the hub plugin that runs inside a session all read the same plans.

## The learning path

The sidebar is one ordered path from zero to publishing your own plugin.

1. **Start.** [Quickstart](/docs/quickstart) takes you from an empty terminal to a finished first task; [Core concepts](/docs/concepts) defines the words every later page uses.
2. **Plugins.** [Why plugins](/docs/plugins) explains how the harness grows by installing plugins, and one page covers each format: [bundle](/docs/publish/bundle), [skill](/docs/publish/skill), [agent preset](/docs/publish/agent-preset), [profile](/docs/publish/profile).
3. **Develop.** Build your own: a [first plugin](/docs/develop/first-plugin), a [tool](/docs/develop/tool), and its [configuration](/docs/develop/configuration).
4. **Use dsh.fish.** Search and install from inside a session with the [hub plugin](/docs/hub) or from a terminal with the [CLI](/docs/cli), then [submit](/docs/submit) your own work.
5. **Reference.** How [scoring](/docs/scoring) works, and the [API](/docs/api) the catalog exposes.

## Why you can trust an install

The catalog reads the real repository or package manifest of everything it lists; a topic tag or a submission is only a discovery seed.

Every install plan is a list of steps you can read before anything runs: packages to add, files to write, settings to change.

A Git package that must run a build script asks for a separate, explicit approval, because that script executes outside the agent sandbox.

## Developer preview

DeepSeek Harness is a developer preview and iterates quickly, with compatibility-breaking changes. These docs describe only behavior verified against the published npm release.

For version-specific options, see the [official DeepSeek Harness guide](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart).
