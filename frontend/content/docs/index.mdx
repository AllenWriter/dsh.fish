DeepSeek Harness is an open-source agent harness. dsh.fish is an independent catalog for finding, checking, and installing things the harness can load. This guide joins the two into one practical path.

## Choose your path

- **New to the harness?** Follow [Quickstart](/docs/quickstart) to launch the Web UI, add a model, choose a workspace, and run a first task.
- **Want a capability?** Use the [hub plugin](/docs/hub) inside a session or the [dsh.fish CLI](/docs/cli) in a terminal. Inspect the plan before installing.
- **Building an integration?** Create a [first plugin](/docs/develop/first-plugin), add a [tool](/docs/develop/tool), then validate its [configuration](/docs/develop/configuration).
- **Ready to share?** Pick the matching [publishing format](/docs/publish/bundle), submit the source, and review the public score.

## What dsh.fish verifies

The catalog reads the repository or package manifest. A topic or submission is only a discovery seed; it does not decide what appears. Every artifact page shows the detected type, source, install plan, maintenance signals, and a reproducible score.

The website, CLI, and hub plugin all consume the same install-plan API. A plan can write files under `$DSH_HOME`, add packages, or patch a profile. Git packages that run build scripts require a separate, explicit approval because those scripts execute outside the agent sandbox.

## Version note

DeepSeek Harness is a developer preview. Commands in this guide are limited to behavior verified in the published npm release. For internals and version-specific options, use the [official DeepSeek Harness guide](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart).
