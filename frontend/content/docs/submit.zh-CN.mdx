---
title: 提交与认领
description: 向 dsh.fish 提交真实源码，由目录重新读取 manifest 并验证 GitHub 所有权。
---

[提交表单](/submit)接收源码标识，如 `npm:<package>` 或 `github:<owner>/<repo>[/<path>]`，以及你认为的类型。目录会重新读取真实 manifest；提交者不能手写爬虫无法验证的目录字段。

`kindHint` 只调整探测顺序，不能替代证据。检测类型与提交类型不一致时会拒绝。

提交需要浏览器会话。若索引器可以读取来源，且当前 OAuth GitHub 账户能够证明仓库所有权，提交会立即通过；其他情况进入审核。设备令牌可以搜索、安装和评分，但不能代替用户发布或认领。

制品创建或 README 变化后，系统按站点语言排队生成本地化内容。源 hash 不匹配时会显示原始 README，避免继续提供过期翻译。
