DeepSeek Harness（`dsh`）是 DeepSeek AI 開源的代理執行框架，一個在你自己機器上執行 AI 代理的程式。它把你選擇的模型連接到讀寫檔案、執行命令的工具上，並記錄代理的每一步操作。

用 `npx @deepseek-ai/dsh web` 在本機啟動後會開啟 Web UI。

dsh.fish 是獨立的 Harness 擴充功能目錄。它負責發現外掛程式、讀取外掛程式的真實內容，並在任何東西寫入你的機器之前展示安裝計畫。

網站、dsh.fish CLI 和在工作階段內執行的 Hub 外掛程式讀取的是同一份計畫。

## 學習路徑

側邊欄是一條從零基礎到發布自己外掛程式的有序路徑。

1. **開始。** [快速開始](/docs/quickstart)帶你從空終端走到完成第一個任務；[核心概念](/docs/concepts)定義之後每頁都會用到的詞彙。
2. **外掛程式。** [外掛程式是什麼](/docs/plugins)解釋 Harness 如何透過安裝外掛擴充能力，每種格式各有一頁：[bundle](/docs/publish/bundle)、[skill](/docs/publish/skill)、[MCP server](/docs/publish/mcp-server)、[agent preset](/docs/publish/agent-preset)、[profile](/docs/publish/profile)、[hook bridge](/docs/publish/hook-bridge)。
3. **開發。** 自己動手：寫[第一個外掛程式](/docs/develop/first-plugin)、一個[工具](/docs/develop/tool)和它的[設定](/docs/develop/configuration)。
4. **使用 dsh.fish。** 在工作階段中用 [Hub 外掛程式](/docs/hub)搜尋安裝，或在終端中用 [CLI](/docs/cli)，然後[提交](/docs/submit)自己的作品。
5. **參考。** [評分](/docs/scoring)如何計算，以及目錄對外提供的 [API](/docs/api)。

## 安裝為何可信

目錄對它列出的每個條目都讀取真實的儲存庫或套件 manifest；主題標籤和使用者提交只是發現入口。

安裝計畫是一份執行前就能閱讀的步驟清單：要新增的套件、要寫入的檔案、要修改的設定。

需要執行建置指令碼的 Git 套件會要求另外明確授權，因為該指令碼在代理沙箱之外執行。

## 開發者預覽

DeepSeek Harness 處於開發者預覽階段，迭代很快，包括破壞相容性的變更。本文件只描述已發布的 npm 版本中驗證過的行為。

版本相關的選項請查閱[官方指南](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart)。
