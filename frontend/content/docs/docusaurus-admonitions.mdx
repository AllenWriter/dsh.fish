---

强调信息用提示块，不要自己画边框。三种写法效果一样。

## 推荐写法

围栏语言写成类型名：

```tip
这是一个提示。适合放下一步、捷径、或者「其实可以更简单」。
```

```info
一般信息。补充背景，不打断主叙述。
```

```warning
需要注意的限制、兼容性，或者会踩的坑。
```

```danger
会出事故的操作。删库、覆盖配置、不可逆的步骤。
```

```success
已经做对了，可以继续下一步。
```

## 也可以用引用

GitHub 警告语法：

> [!NOTE]
> 和 ```note 一样，会收成提示块。

或者旧的 Docusaurus 习惯，第一行写类型名：

> **tip**
> 这是一个提示块。

## 代码块本身

普通代码仍然是带顶栏和复制按钮的围栏：

```ts
export const n = 1
```
