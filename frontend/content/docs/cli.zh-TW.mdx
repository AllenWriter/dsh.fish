`@dsh-fish/cli` 在終端安裝 [dsh.fish](https://dsh.fish) 構件。構件頁上的安裝命令就是這個二進位：它執行的安裝計畫與網站渲染、`@dsh-fish/hub` 外掛程式執行的是同一份。所有寫入都落在 DeepSeek Harness 的 `$DSH_HOME` 裡。

## 安裝構件

```sh
npx @dsh-fish/cli add release-notes
npx @dsh-fish/cli add https://dsh.fish/a/release-notes --profile web
npx @dsh-fish/cli add acme/notes
```

`add` 把 Hub id、dsh.fish URL 或 `owner/repo` 解析到目錄中的構件，然後執行計畫：

- 向 `$DSH_HOME` 寫檔案
- 用套件管理器加套件
- 寫入配置檔案補丁列

從原始碼建置的 git 套件會被拒絕，直到你傳入 `--allow-build-scripts`。這個旗標允許該套件的 `prepare` 指令碼在這台機器上執行，處於代理沙箱之外。

`--yes` 只會跳過確認提示，不會授予這項權限。

## 其他命令

| 命令                               | 作用                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| `find [query]`                     | 搜尋目錄（`--kind` 限定一種類型）。                          |
| `show <source>`                    | 展示一個構件和安裝它會執行的命令。                           |
| `list`                             | 列出這台機器透過 CLI 或 hub 外掛程式安裝的構件。             |
| `remove <id>`                      | 撤銷已記錄的檔案、補丁列和套件。                             |
| `update [id]`                      | 重新執行目前計畫。                                           |
| `init [name]`                      | 寫一個 hub 索引器能接受的 `SKILL.md`。                       |
| `login` / `logout` / `whoami`      | 裝置登入的帳號，與 hub 外掛程式共用同一個 token。            |
| `rate <source> <1-5> [comment...]` | 給構件評分，覆蓋你之前的評分。需要先 `login`。               |
| `reviews <source>`                 | 平均分、5 到 1 星的分布和最近的評論。                        |

```sh
npx @dsh-fish/cli find postgres --kind mcp-server
npx @dsh-fish/cli list --json
npx @dsh-fish/cli remove release-notes
npx @dsh-fish/cli init my-skill
npx @dsh-fish/cli rate dsh-postgres-mcp 5 "installed and queried in minutes"
```

## 評分

站內採用 1–5 星制：1 星表示不能用或有誤導，5 星表示出色。`reviews` 是匿名的；`rate` 需要先 `login`，且始終以登入帳號的名義發表。再次評分會覆蓋之前那次。

驅動這個 CLI 的代理應遵守 hub 外掛程式 `hub_rate` 工具聲明的同一條規則：只給實際安裝並使用過的構件評分，依據第一手證據，並在評分時告知使用者。

## 選項

| 選項                    | 說明                                                        |
| ----------------------- | ----------------------------------------------------------- |
| `--profile, -p`         | Harness 配置檔案（預設 `$DSH_PROFILE` 或 `web`）。          |
| `--registry`            | Hub 來源（預設 `$DSH_FISH_URL` 或 `https://dsh.fish`）。    |
| `--kind, -k`            | 把 `find` 限定到一種構件類型。                              |
| `--allow-build-scripts` | 允許 git 套件執行它的 prepare 指令碼。                      |
| `--json`                | 機器可讀輸出。                                              |
| `--yes, -y`             | 跳過確認提示，不授予建置指令碼權限。                        |
