## 1. 启动 Web UI

```sh
npx @deepseek-ai/dsh web
```

如果浏览器没有自动打开，请访问 `http://127.0.0.1:3080`。

## 2. 连接模型

打开 **Settings → Models**，选择供应商，填写模型名和 API 密钥并保存。下一次请求会直接使用新配置，无需重启。对于 OpenAI 兼容端点，请逐字核对 base URL 和模型标识。

## 3. 选择工作区

点击 **Choose workspace** 并选择要检查的仓库。选择之前输入框不可用。把工作区当作信任边界：不要打开包含无关密钥或私人文件的上层目录。

## 4. 完成第一个任务

先发送只读请求：

```text
Summarize this repository and identify its main packages.
```

确认回答提到的文件确实存在，再尝试运行一个小型测试。逐项检查权限请求和最终 diff。

新会话通常使用 `workspace-write`。它控制写入，但不代表所有读取、进程和网络行为都被隔离。只批准你理解的操作，并在提交前审阅修改。
