Это руководство ведёт от пустого терминала до рабочей сессии DeepSeek Harness за четыре шага. DeepSeek Harness (`dsh`) — это [агентная обвязка](/docs/concepts) (agent harness): программа, которая запускает языковую модель в цикле с инструментами, чтобы она могла читать файлы, выполнять команды и править код за вас. [Сессия](/docs/concepts) — это один разговор с таким агентом. Каждый новый термин при первом упоминании ссылается на страницу основных понятий, где он определён полностью.

API-ключ хранится на вашей машине, а запросы к модели не проходят через dsh.fish.

## 1. Запустите Web UI

```sh
npx @deepseek-ai/dsh web
```

Команда запускает Web UI по адресу `http://127.0.0.1:3080` и открывает его в браузере. Если браузер не открылся, перейдите по этому адресу вручную. Пакет находится в стадии developer preview, поэтому перед важной работой прочитайте подсказку npm и примечания к выпуску.

## 2. Подключите модель

Обвязке нужна [модель](/docs/concepts): LLM, которая выполняет рассуждение и предоставляется сервисом вроде DeepSeek, Anthropic или OpenAI. Откройте **Settings → Models**, введите API-ключ провайдера и сохраните. Карточке DeepSeek нужен только ключ. Другие провайдеры добавляются через **Add provider**, а корпоративный шлюз или собственный сервер — через **Add a custom provider**. Ключ хранится на вашей машине в домашнем каталоге обвязки (`$DSH_HOME`) и не отправляется в dsh.fish. Следующий запрос использует новую конфигурацию, перезапуск не нужен.

Для OpenAI-совместимого сервиса проверьте base URL и идентификатор модели посимвольно. Сохранённый ключ не доказывает, что сервис принимает выбранную модель, поэтому перед долгой сессией выполните маленькую первую задачу ниже.

## 3. Выберите рабочую область

[Рабочая область](/docs/concepts) — это каталог проекта, который агент может просматривать и изменять. Нажмите **Choose workspace** и откройте репозиторий, который должен изучить агент. Поле ввода (composer) недоступно, пока не выбрана рабочая область.

Считайте рабочую область границей доверия: агент читает и пишет внутри неё. Сначала просмотрите репозиторий и не открывайте каталог с посторонними секретами.

## 4. Выполните первую задачу

Отправьте запрос только на чтение:

```text
Summarize this repository and identify its main packages.
```

Убедитесь, что названные в ответе файлы существуют. Затем попросите небольшое проверяемое действие, например запуск одного теста. Проверяйте каждое запрошенное разрешение и итоговый diff.

## Разберитесь с разрешениями

[Разрешения](/docs/concepts) определяют, что агент может делать, не спрашивая. Новая сессия начинается с пресета `workspace-write`: агент может писать в рабочую область, но это не изолирует все чтения, процессы и сетевые действия. Одобряйте только те операции, которые понимаете, держите учётные данные вне рабочей области и проверяйте изменения перед коммитом.

## Дальше

- Добавьте поиск по каталогу и установку с [плагином dsh.fish Hub](/docs/hub).
- Автоматизируйте задачи в терминале через профиль headless: `dsh --profile headless "run the tests"` запускает одну сессию, печатает финальный ответ и завершается.
- Создайте свою возможность в [Первый плагин](/docs/develop/first-plugin).

Официальный справочник по конкретной версии: [Use the Web UI](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart).
