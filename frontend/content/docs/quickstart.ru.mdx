## 1. Запустите Web UI

```sh
npx @deepseek-ai/dsh web
```

Если браузер не открылся, перейдите на `http://127.0.0.1:3080`.

## 2. Подключите модель

Откройте **Settings → Models**, выберите провайдера, введите модель и API-ключ, затем сохраните. Новая конфигурация применяется к следующему запросу без перезапуска. Для OpenAI-совместимого сервиса точно проверьте base URL и идентификатор модели.

## 3. Выберите рабочую папку

Нажмите **Choose workspace** и выберите репозиторий. Считайте папку границей доверия: не открывайте родительский каталог с посторонними секретами или личными файлами.

## 4. Выполните первую задачу

```text
Summarize this repository and identify its main packages.
```

Убедитесь, что названные файлы существуют, затем попросите запустить один небольшой тест. Проверяйте каждое разрешение и итоговый diff. `workspace-write` контролирует запись, но не изолирует все чтения, процессы и сетевые действия.

Далее установите [плагин Hub](/docs/hub) или создайте [первый плагин](/docs/develop/first-plugin).
