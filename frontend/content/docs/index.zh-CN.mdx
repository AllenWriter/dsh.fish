DeepSeek Harness（`dsh`）是 DeepSeek AI 开源的智能体运行框架，一个在你自己机器上运行 AI 智能体的程序。它把你选择的模型连接到读写文件、运行命令的工具上，并记录智能体的每一步操作。用 `npx @deepseek-ai/dsh web` 本地启动后会打开 Web UI。

dsh.fish 是独立的 Harness 扩展目录。它负责发现插件、读取插件的真实内容，并在任何东西写入你的机器之前展示安装计划。网站、dsh.fish CLI 和在会话内运行的 Hub 插件读取的是同一份计划。

## 学习路径

侧边栏是一条从零基础到发布自己插件的有序路径。

1. **开始。** [快速开始](/docs/quickstart)带你从空终端走到完成第一个任务；[核心概念](/docs/concepts)定义之后每页都会用到的词汇。
2. **插件。** [插件是什么](/docs/plugins)解释 Harness 如何通过安装插件扩展能力，每种格式各有一页：[bundle](/docs/publish/bundle)、[skill](/docs/publish/skill)、[MCP server](/docs/publish/mcp-server)、[agent preset](/docs/publish/agent-preset)、[profile](/docs/publish/profile)、[hook bridge](/docs/publish/hook-bridge)。
3. **开发。** 自己动手：写[第一个插件](/docs/develop/first-plugin)、一个[工具](/docs/develop/tool)和它的[配置](/docs/develop/configuration)。
4. **使用 dsh.fish。** 在会话中用 [Hub 插件](/docs/hub)搜索安装，或在终端中用 [CLI](/docs/cli)，然后[提交](/docs/submit)自己的作品。
5. **参考。** [评分](/docs/scoring)如何计算，以及目录对外提供的 [API](/docs/api)。

## 安装为什么可信

目录对它列出的每个条目都读取真实的仓库或包清单；主题标签和用户提交只是发现入口。安装计划是一份执行前就能阅读的步骤列表：要添加的包、要写入的文件、要修改的设置。需要运行构建脚本的 Git 包会要求单独明确授权，因为该脚本在智能体沙箱之外执行。

## 开发者预览

DeepSeek Harness 处于开发者预览阶段，迭代很快，包括破坏兼容性的变更。本文档只描述已发布的 npm 版本中验证过的行为。版本相关的选项请查阅[官方指南](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart)。
