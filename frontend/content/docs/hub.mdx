---
title: Hub plugin
description: Find, inspect, and install dsh.fish artifacts from inside an agent session.
---

The hub plugin (`dsh-hub`) puts the dsh.fish catalog inside a running session. The agent can search for an artifact, show you what installing it would do, and install it once you agree. You never leave the session.

## Add the plugin

```sh
dsh plugin --profile web add github:stvlynn/dsh.fish#main
```

The package is TypeScript, so a git install runs its `prepare` script to build `lib/`. pnpm 10 and later refuse that until you allow it. Copy the package key pnpm prints into your profile's `pnpm-workspace.yaml`:

```yaml
allowBuilds:
  dsh-hub: true
```

Then run the `add` again. This allowance lets the package's own code run on your machine at install time, outside the agent's sandbox. Pin a commit so a later push cannot change what runs.

## Find

`hub_search` searches the catalog by free text, and a `kind` argument restricts results to one artifact type. It returns ids you pass to the other hub tools. Reading the catalog needs no account.

## Inspect

`hub_show` shows one artifact in detail, including the exact commands installing it would run on this machine. `hub_reviews` reads community ratings anonymously: the 1–5 star average, the distribution, and recent comments. Check both before you let the agent install anything. The website shows the same evidence if you prefer to look there.

## Install

`hub_install` applies the install plan on this machine: it writes skill and preset files, adds MCP and hook rows to the profile's patch layer, and runs the package manager for bundles. Restart the harness afterwards so the new rows load.

If a plan step builds a package from source, `hub_install` refuses until the caller passes `allowBuildScripts: true`. That step runs the package's code on your machine at install time, outside the agent sandbox, so the agent must come back and ask you. It cannot grant this on its own.

Successful installs are recorded in `$DSH_HOME/.dsh-fish-lock.json`. `hub_list` shows what this machine installed, `hub_update` re-applies the current plan for an installed artifact, and `hub_remove` reverses a recorded install (files, patch rows, packages). The lockfile is shared with `@dsh-fish/cli`, so the [CLI](/docs/cli) sees the same installs.

## Sign in

Signing in attributes installs to your account and unlocks `hub_rate`. Reading the catalog needs no account.

`hub_account` with `action: "login"` starts an OAuth device flow: the tool returns a short code and a URL, you open the URL in a browser and approve, and the plugin polls until you do. The agent cannot approve it for you. The token is written to `$DSH_HOME/.dsh-fish-token.json` with file mode 0600 and is never logged.

This token is weaker than a browser session on purpose. It can read the catalog, resolve install plans, and rate artifacts as you. It cannot submit or claim artifacts.

## Safety

File-writing steps are fenced to the resolved `$DSH_HOME`; a plan that tries to escape it is refused. Build-from-source steps need your explicit consent, as described above. `hub_rate` carries its own rule: the agent rates only what this machine actually installed and used, from firsthand evidence, and tells you when it leaves a rating.

## Tools

| Tool          | What it does                                                              |
| ------------- | ------------------------------------------------------------------------- |
| `hub_search`  | Search the registry by text and artifact kind.                            |
| `hub_show`    | One artifact in detail, including exactly what installing it would do.    |
| `hub_install` | Apply the install plan on this machine.                                   |
| `hub_list`    | Artifacts this machine already installed through the hub.                 |
| `hub_remove`  | Reverse a recorded install (files, patch rows, packages).                 |
| `hub_update`  | Re-apply the current plan for an installed artifact.                      |
| `hub_account` | Sign in via the OAuth device flow, check status, or sign out.             |
| `hub_reviews` | Community ratings: the site's 1–5 scale, average, distribution, comments. |
| `hub_rate`    | Rate an installed artifact 1–5 stars, optionally with a public comment.   |

## Configuration

```yaml
- id: hub
  name: dsh-hub
  config:
    baseUrl: https://dsh.fish # a self-hosted deployment only changes this
    targetProfile: current # or a specific profile name
```
