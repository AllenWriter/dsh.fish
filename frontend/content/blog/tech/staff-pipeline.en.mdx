## A convincing rehearsal

I wrote full persona docs for a digital staff: one person takes the job, one transcribes, one outlines, one drafts, one prepares a paste-ready post. The roles were complete. The handoff diagram looked good. Once it actually ran, two things showed up. Transcription lived in two toolchains. Publishing had no API, only a pasteable draft. Finished audio went down a different pipe. Until those pipes met, the team was only a convincing rehearsal.

## A persona is not a product

Digital employees slide into cosplay. The more complete the character sheet, the more it feels like you already shipped. A persona is not a product. Where the file goes, what counts as done, where the next person reads from: if those three sentences are fuzzy, the pipeline is still a dress rehearsal.

## The shortest path first

My test is plain. Can a piece move from inbox to a draft I can take, or to audio I can air. If it cannot, a busy team is still rehearsing. Clear the shortest path first: a link in, a manuscript out. Add other capabilities later. Stack too many and the inlet blurs again. Same disease as too many folders.
