## うまく見えるリハーサル

デジタル従業員のために、一通りのペルソナ文書を書きました。誰が仕事を受け、誰が文字起こしし、誰がアウトラインを出し、誰が原稿を書き、誰が貼り付け用の投稿を用意するか。役割は揃っていた。引き継ぎ図も見栄えがよかった。実際に走らせて、二つのことが見えました。文字起こしは二つのツールチェーンに住んでいた。公開には API がなく、貼れる原稿しか出ない。完成した音声は別の管を通る。管がつながるまで、チームはうまく見えるリハーサルにすぎませんでした。

## ペルソナはプロダクトではない

デジタル従業員はコスプレに滑りやすい。キャラクターシートが揃うほど、もう出荷した気になる。ペルソナはプロダクトではありません。ファイルはどこへ行くか、何をもって完了とするか、次の人はどこから読むか。この三文が曖昧なら、パイプラインはまだ通し稽古です。

## まず最短の道

私のテストは素朴です。一篇が Inbox から、持ち帰れる原稿へ、あるいは放送できる音声へ動くか。動かなければ、忙しいチームもまだ稽古中です。最短の道を先に通す。リンクが入って、原稿が出る。ほかの能力はあとで足す。積みすぎると入口がまた濁る。フォルダが多すぎるのと同じ病です。
