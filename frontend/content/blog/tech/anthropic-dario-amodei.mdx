## 开场

OpenAI 和 Anthropic，是全世界最具影响力的两家 AI 公司。

这两家公司的两位 CEO 曾经被安排站在舞台上，大家准备牵手合照，但他们死都不牵。

这两位闹翻的老同事，现在根本就是死对头。

而且 Dario 这边，还在超级碗送了他们一个超级讽刺的广告。

这波操作真的有够狠，可以说把 OpenAI 的 Altman 打到破防了。

Anthropic 到底是怎么在短短两年内，在企业 AI 市场把 OpenAI 给打趴的？

## 先看数字

我们先来看数字。

2023 年的时候，企业 AI 市场还是 OpenAI 的天下，市场占有率有一半。当时 Anthropic 才 12%，大家都以为胜负已经很清楚了。

结果到了 2025 年底，剧情大逆转。

Anthropic 涨到了 40% 左右，OpenAI 反而掉到了 20% 多。

看营收更夸张。

Anthropic 在 2023 年才只有 1 亿美金左右，2024 年变成 10 亿，2025 年直接逼近 100 亿，三年翻了快 100 倍。

Epoch AI 今年 2 月最新的分析就说，照这个速度下去，Anthropic 今年年中的总营收就会超过 OpenAI，变成全球最赚钱的 AI 公司。

这家公司凭什么能在两年内弯道超车？

## Dario Amodei 的背景

我们得从他们的老大 Dario Amodei，当初为什么要出来创立 Anthropic 开始说起。

1983 年，Dario 在旧金山出生。

他家里完全不是走那种硅谷精英路线。爸爸是意大利裔的皮革工匠，妈妈是犹太裔的图书馆专案经理。

他从小在旧金山的 Mission District 长大。熟旧金山的人就知道，那边本来就不是什么高级住宅区。

高中的时候，刚好碰到网路泡沫，身边的人都在想怎么写程式发大财，但他完全没兴趣。

2000 年，17 岁的 Dario 入选美国物理奥林匹克国家队。大学先读加州理工，后来转到斯坦福读物理，研究所又跑到普林斯顿，拿了个生物物理博士。

所以你看，他其实是个物理学家，同时也是神经科学博士。这种双重的学术背景，让他看事情的角度，跟硅谷那票 AI 创业者完全不一样。

## 父亲去世对他的影响

2010 年，他爸爸因为慢性骨髓性白血病过世了。

但是就在他爸爸走后没几年，第二代靶向药物就做出来了。他爸爸那种癌症的存活率，直接从 50% 拉到 95%。

如果科学进步的速度再快那么一点点，他爸爸今天可能还在。

这件事彻底改变了 Dario。

他开始想，如果有一种技术可以大幅加速科学研究的进度，像他爸爸这样的悲剧就不会再发生了。

最后，他在 AI 身上看到了这个机会。

## 从百度到 OpenAI

2014 年，他 31 岁，先去了百度在硅谷的 AI 实验室，后来又去了 Google Brain。

2015 年夏天，马斯克跟 Altman 办了那场很有名的 Rosewood 饭店晚宴，找了 Dario 和 Ilya 这批顶尖的 AI 研究员过去。Dario 也就这样成了 OpenAI 最早期的核心班底。

在 OpenAI 那几年，他亲手做出了 GPT-2 和 GPT-3。他的团队还开发了 RLHF，也就是人类回馈强化学习技术。就是这个东西，让 AI 变得听话、好用，而且更安全。

## 为什么离开 OpenAI

但是在 OpenAI 的这四年里，他跟 Altman 在 AI 到底该怎么做这件事上，有太多意见不合的地方。

这个感觉就像是你发明了一款新药，动物实验看起来不错，但人体实验还没做完。

Altman 的想法是，先上市，边卖边看副作用，用规模来收集数据。

但 Dario 觉得，就要先完整做完人体临床试验，确定百分之百安全了再推出去，就算对手先抢到市场也没关系。

Dario 到了 2020 年底，实在待不下去了。

他带着妹妹 Daniela，还有几个从 Google Brain 时期就认识的朋友，一共七个人集体辞职。这也是 OpenAI 早期最大的人才大出走。

## Anthropic 是怎么创立的

2021 年，这七个人用几乎平分股权的方式，开了 Anthropic。

他们还特地注册成一种比较特殊的公司结构。

意思是说，如果哪天 CEO 为了安全考量，不肯上线新模型，股东在法律上是告不掉他的。

他们是真的把“做安全的 AI”写进了公司章程里。

## 明明能更早上线 Claude，却选择继续测

其实在 2022 年夏天，ChatGPT 出来之前，他们就已经训练好第一版 Claude 了。

本来可以抢先一步上线，但他们选择继续做更多的安全测试。

结果几个月后，OpenAI 的 ChatGPT 一做完就直接推出去，瞬间引爆全球。

Anthropic 确实因此错失了抢头香的机会，但也证明了，他们是真的把安全可靠摆在第一位。

## 核心团队为什么这么稳

快转到现在。

你看马斯克的 xAI，12 个共同创办人跑了一半，不只创办人，连财务长都待了没多久就闪人。

再回头看 OpenAI，11 个创始成员现在只剩 3 个。走掉的有跟 Altman 闹翻的马斯克，也有发动董事会政变失败后走人的，还有像 Andrej Karpathy、John Schulman 这些教科书等级的大牛，全都走了。

那你再看看 Anthropic。

7 个共同创办人，顶着创业最怕的那种平分股权架构，成立 5 年到现在居然一个都没走。

还可以这么稳，其实是因为另一个大家都没注意到的关键人物：Dario 的妹妹，Daniela Amodei。

## Daniela Amodei 的角色

大部分 AI 公司，都是技术人当家。创办人是天才科学家，但根本不懂怎么管人、管钱、管组织。

Anthropic 的高层却是一个非常少见的组合：兄妹一起管公司。

Daniela 大学念的是英国文学。2013 年，她是 Stripe 的第 45 号员工。

在 Stripe 的那五年，她亲眼看着一家新创公司怎么从几十个人膨胀到几千人，而且还没乱掉。

她很清楚，天才工程师如果很难搞，对团队合作绝对是毁灭性的打击。

所以她弄了一套流程，专门刷掉那些高智商混蛋。

所以在 Anthropic，不管你技术多强，只要价值观不合，就不录用。

他们宁愿不要顶尖人才，也不让价值观不合的人混进来。

## 为什么能在企业市场大逆转

好，了解了 Anthropic 这么稳定的核心团队后，我们来看看他们到底是怎么在企业市场大逆转的。

首先，从开张第一天起，Anthropic 的策略就定死了：不碰大众市场，不搞花哨的产品，只盯企业客户的需求。

很多人以为 AI 安全只是个很虚的行销口号，但对企业客户来说，安全就是防火墙，而防火墙刚好就是大企业最在乎的。

你想想看，银行敢让 AI 把客户资料弄出去吗？药厂敢让 AI 给错医疗建议吗？保险公司要求每一次 AI 互动都要能追踪、能查核，而且所有受监管的行业，AI 都得符合欧洲跟各国的法规。

这些最基本的门槛过不了，你连进场简报的资格都没有。

Anthropic 从第一天开始，就把这些需求写进底层架构里。

结果就是，像 IBM、辉瑞、诺和诺德，还有挪威主权财富基金，这些对资安要求严格到不行的跨国巨头，一个接一个选了 Anthropic。

## Claude Code 为什么是翻盘点

如果说安全是让企业点头的基本盘，那 2025 年 5 月推出的 Claude Code，就是让 Anthropic 彻底翻盘的关键。

Claude Code 已经不只是工具了，它根本就是一个能直接帮你把专案做完的资深工程师。

第一，它有闭环能力。

你叫它重构一段 API，它会自己在终端机跑测试，看到报错就自己改，一直改到测试全部亮绿为止。

第二，它对超大型的程式码库非常有概念。

多数 AI 处理单一档案很厉害，但遇到几万行的企业级专案就傻了。Claude Code 可以在不同档案间穿梭，精准抓到变数定义跟各种依赖关系。

第三，它的幻觉率比对手低非常多。

当它不确定某个函数库怎么用时，它会自己去查文件，而不是在那边瞎编一个不存在的语法。

Google Gemini API 团队的一位首席工程师就公开讲过，Claude Code 只花了一个小时，就写出一个 Google 内部搞了一整年才弄出来的价格设计。

就连 OpenAI 的创办成员 Andrej Karpathy 也常常说，写程式这件事，Claude 绝对是他的首选。

甚至 Claude Code 的开发者都承认，Claude 自己的很多程式码，都是 Claude 自己写给自己的。

## 企业客户为什么愿意买单

这就让 Anthropic 的企业客户，两年内从不到一千家暴增到 30 万家以上。

一年花超过 10 万美金的大客户，一年内足足成长了七倍多。

现在我们来看 Anthropic 跟 OpenAI 这场大战的本质。

OpenAI 很大一部分的钱，是来自一般消费者订阅，平均一个人可能就掏二十几块美金。

Anthropic 很大一部分的钱，则来自企业大单跟 API 调用。每个付费用户平均贡献的金额，差距非常大。

大家把 ChatGPT 当超级搜寻、查资料、做翻译、问生活琐事。这种东西在大家心里的定价，就是 Google 等级，免费最好，收个 20 美金已经觉得很贵了。

Anthropic 在企业里完全不一样。它是在解决真正的商业问题。

传统 AI 顶多给你点建议，但 Claude Code 是直接接管整个开发环境，自己跑测试、自己抓 bug。企业在算这笔账的时候，对标的是一个年薪百万的资深工程师。

这样一比，花个几百块美金的 API 费用，简直便宜到爆。

## OpenAI 和 Anthropic 打的是不同的仗

结果就是，Anthropic 用只有 ChatGPT 一小部分的用户量，就挖走了企业 AI 支出里最值钱的大饼。

而且企业市场有一种消费市场没有的特性。

今天用 ChatGPT，明天试 Gemini，后天换 Claude，切换成本几乎没有。

但一家银行如果花了半年，把 Claude 接进它们的信贷、审查和内部系统里，你叫它明天换成 GPT，这根本不可能。

这就是为什么 Anthropic 的营收结构非常健康。

企业合约动不动都是好几年，数字好预测，毛利也高。

当 OpenAI 还在猛冲消费端，想弄出更多免费用户的时候，Anthropic 则是静静吃大客户，把重心全放在企业市场。

两家公司表面上在同一个赛道，其实打的是完全不同的仗。

等 OpenAI 回过神来，想认真抢企业市场的时候，Anthropic 早就把最有价值的那批客户给牢牢绑死了。

## 结尾

现在你知道了，Anthropic 的逆袭，根本就是一个注定的结果。

相比 Altman，Dario 的作风一直都非常务实。他就是一心全放在技术上，专注研发，把拉关系或话题炒作这种事全都放在后面。

就像 Google 前 CEO Eric Schmidt 投资 Anthropic 的时候讲的，在最早期那个阶段，你什么数据都没有，没有营收，没有市场，没有产品，你赌的就是 Dario 这个人。

在这场人类史上最重要的 AI 世纪大战里，市场赌的是速度，投资人赌的是人，而 Dario 赌的，是一个如果当年早一点出现，或许就能救回他爸爸的，那个安全、负责任的 AI。
