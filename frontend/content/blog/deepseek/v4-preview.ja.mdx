DeepSeek は 2026 年 4 月 24 日に [DeepSeek-V4 プレビュー](https://www.deepseek.com/news/v4-preview/) を出した。一次ソースはその記事です。ここは転載ではなく、Harness v0.1.2-alpha.1 時点で、その発表がこのカタログが索引する agent ランタイムに何をしたかの追跡です。

## 発表が書いたこと

オープンウェイトの二モデル。公式サービス上の既定コンテキストはどちらも **1M token**：

| モデル | 総パラメータ / 活性 | 発表での位置づけ |
| --- | --- | --- |
| DeepSeek-V4-Pro | 1.6T / 49B | プログラミング、世界知識、数学 — クローズドソースに並ぶ |
| DeepSeek-V4-Flash | 284B / 13B | より速く安く。「単純な Agent タスクでは Pro と同等」 |

アーキテクチャの主張は **token 次元の圧縮と DSA**（DeepSeek Sparse Attention）。1M は任意の長コンテキスト SKU ではなく、標準ウィンドウです。

API の `base_url` は変わりません。`model` は `deepseek-v4-pro` または `deepseek-v4-flash`。どちらも思考 / 非思考をサポート。発表は Agent 用途に思考モード、強度 `max` を勧めています。

**廃止：** `deepseek-chat` と `deepseek-reasoner` は **2026 年 7 月 24 日 15:59 UTC** に停止。それまではそれぞれ V4-Flash の非思考と思考へルーティング。期限後、これらの文字列は別名ではなく死名です。

Web と App は専門家モード / 極速モードとしてこの対を出します。重みと技術報告は発表ページから（Hugging Face / ModelScope、arXiv）。

## Harness がしたこと

V4 発表は四月。八月に実際に走っている harness プレビューは、V4 を生きた家系として扱っています。

- **v0.1.1-rc.1** は公式アダプタに `DeepSeek-V4-Flash-Vision-Exp` を追加 — 画像入力、実験的、名前に Exp。
- **v0.1.1-rc.2** はアダプタに **Files API** 経由の画像アップロードと再利用を優先させ、モデルの要求どおり拡大縮小と形式変換。
- **v0.1.0-rc.8** はすでに DeepSeek アダプタでネイティブ画像リクエストを開いていた（`/goal`、`/plan`、`@` によるファイルとセッション参照）。
- **v0.1.2-alpha.1** は**有効プラグインのパッケージ名とバージョン**を公式 DeepSeek リクエストに付け、任意の Session ログアップロードを提供。

発表の「Claude Code、OpenClaw、OpenCode、DeepSeek 自前の coding agent との統合」は、未改修ランタイムの横に貼った宣伝ではありません。その後の数か月で vision、Files API、プラグインの身元がこの API の一等になりました。

実験的視覚モデルは別の `model` 文字列：`deepseek-v4-flash-vision-exp`。API 文書は現在 `deepseek-v4-flash` を DeepSeek-V4-Flash-0731、`deepseek-v4-pro` を DeepSeek-V4-Pro-0813 と書きます。名前は同じ、スナップショットが更新されます。呼び出し方は変わりません。

## プラグイン著者が無視できないこと

1. **`deepseek-chat` / `deepseek-reasoner` を呼び出し方として書かない。** 廃止日があります。四月に正しかった README は 2026 年 7 月 24 日に誤ります。
2. **1M が公式アダプタの周りのウィンドウ。** 128k トリムを仮定する skill、検索戦略なしでリポジトリ全体を一度の prompt に入れる skill は、ウィンドウを浪費するか別の形で溢れます。
3. **画像は一等のツール結果**であり、サイドバーではありません。スクリーンショット、図、diff 図を出すプラグインは、公式アダプタが Files API と vision-exp を使います。圧縮時にそれらを数えよ（v0.1.2-alpha.1 は数えています）。
4. **公式アダプタは DeepSeek にどのプラグインが載ったかを伝えられる。** 恥ずかしい、誤解を招く、衝突するパッケージ名は、今はリクエストと一緒に出ます。

## このカタログがしないこと

dsh.fish はモデルを選びません。インストール計画は API キーを書きません。V4 発表の価格とピーク時間帯は [DeepSeek API 文書](https://api-docs.deepseek.com/quick_start/pricing) であり、カタログ行ではありません。

カタログの仕事は、インストール計画を V4 が実際に走るランタイムに合わせることです。プラグイン README がまだ `export deepseek-chat` と書くなら、それはメンテナンス点に入れられる文書欠陥であり、別製品ではありません。
