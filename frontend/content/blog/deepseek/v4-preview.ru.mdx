24 апреля 2026 DeepSeek опубликовал [превью DeepSeek-V4](https://www.deepseek.com/news/v4-preview/). Первоисточник — та статья. Здесь не пересказ, а прослеживание: что это объявление сделало с agent-рантаймом, который индексирует каталог, к Harness v0.1.2-alpha.1.

![После объявления V4 adapter DeepSeek Harness менялся поэтапно.](/blog/diagrams/v4-adapter-timeline.svg)

## Что объявление реально написало

Две модели с открытыми весами. На официальном сервисе у обеих контекст по умолчанию **1M токенов**:

| Модель            | Всего / активных параметров | Роль в объявлении                                                 |
| ----------------- | --------------------------- | ----------------------------------------------------------------- |
| DeepSeek-V4-Pro   | 1.6T / 49B                  | программирование, знания о мире, математика — вровень с закрытыми |
| DeepSeek-V4-Flash | 284B / 13B                  | быстрее и дешевле; «на простых Agent-задачах сопоставим с Pro»    |

Архитектурное утверждение — **сжатие по оси токенов плюс DSA** (DeepSeek Sparse Attention). 1M — не опциональный SKU длинного контекста, а стандартное окно.

`base_url` API не меняется. `model` становится `deepseek-v4-pro` или `deepseek-v4-flash`. Оба имени поддерживают thinking / non-thinking. Объявление советует для Agent thinking-режим с силой `max`.

**Снятие:** `deepseek-chat` и `deepseek-reasoner` останавливаются **24 июля 2026, 15:59 UTC**. До того они вели на non-thinking и thinking V4-Flash. После срока эти строки — мёртвые имена, не алиасы.

Веб и приложение показывают эту пару как экспертный / скоростной режим. Веса и отчёт — со страницы объявления (Hugging Face / ModelScope, arXiv).

## Что сделал Harness

Объявление V4 — апрель. Августовское превью harness уже держит V4 живым семейством:

- **v0.1.1-rc.1** добавил в официальный адаптер `DeepSeek-V4-Flash-Vision-Exp` — картинки, экспериментально, Exp в имени.
- **v0.1.1-rc.2** заставил адаптер предпочитать загрузку картинок через **Files API** и переиспользовать уже загруженные файлы, масштабируя и конвертируя по требованиям модели.
- **v0.1.0-rc.8** уже открыл нативные запросы картинок в адаптере DeepSeek (`/goal`, `/plan`, `@` на файлы и сессию).
- **v0.1.2-alpha.1** вешает **имена и версии включённых плагинов** на официальные запросы DeepSeek и даёт опциональную выгрузку Session-лога.

Фраза объявления про интеграцию с Claude Code, OpenClaw, OpenCode и собственным coding agent DeepSeek — не маркетинг рядом с нетронутым рантаймом. За следующие месяцы vision, Files API и идентичность плагинов стали гражданами первого класса на этом API.

Экспериментальная visual-модель — отдельная строка `model`: `deepseek-v4-flash-vision-exp`. Документация API сейчас пишет, что `deepseek-v4-flash` это DeepSeek-V4-Flash-0731, `deepseek-v4-pro` — DeepSeek-V4-Pro-0813. Имя то же, снимок обновился. Способ вызова не меняется.

## Окно в 1M меняет бюджет, но не отменяет поиск

Большее контекстное окно снижает риск обрезки, но не делает бесплатной безразборную загрузку всего репозитория. Ввод по-прежнему требует времени и денег, повторяющиеся файлы конкурируют с результатами инструментов, а длинной сессии всё ещё нужна compaction. Автору плагина стоит считать 1M увеличенным бюджетом с той же задачей учёта: выбирать доказательства, сохранять важные решения и оставлять место для ответа.

У Vision есть второй бюджет. Files API позволяет не загружать один и тот же материал повторно, а resize и преобразование в adapter приводят изображение к формату выбранной модели. Ни один из этапов не решает, нужно ли это изображение. Инструмент, который возвращает десять почти одинаковых скриншотов, должен удалить дубликаты до выдачи результата.

## Минимальная проверка миграции

Найдите устаревшие строки model в конфигурации и примерах, затем проверьте именно ту modality, которую создаёт ваш плагин.

```text
deepseek-chat       → deepseek-v4-flash
deepseek-reasoner   → deepseek-v4-pro (thinking выбирается явно)
```

Не применяйте эту замену к workload автоматически. У Flash и Pro разные цели по цене и возможностям, а thinking intensity выбирается отдельно. Зафиксируйте нужную model в Profile, выполните характерную задачу и проверьте работу изображений и files через официальный adapter до обновления README.

## Чего автору плагина нельзя игнорировать

1. **Не пишите `deepseek-chat` / `deepseek-reasoner` как способ вызова.** У них есть дата снятия. README, верный в апреле, 24 июля 2026 уже неверен.
2. **1M — окно, вокруг которого крутится официальный адаптер.** Skill, который режет по 128k или пихает весь репозиторий в один prompt без поиска, теперь либо тратит окно, либо переполняется иначе.
3. **Картинки — результаты инструментов первого класса**, не боковая панель. Плагин, который выдаёт скриншоты, графики или diff-картинки, пойдёт через Files API и vision-exp. Считайте их при сжатии (v0.1.2-alpha.1 уже считает).
4. **Официальный адаптер может сказать DeepSeek, какие плагины загружены.** Позорное, вводящее в заблуждение или конфликтующее имя пакета теперь уходит вместе с запросом.

## Чего этот каталог не делает

dsh.fish не выбирает модель за вас. План установки никогда не пишет API-ключ. Цены и часы пика из объявления V4 — это [документация DeepSeek API](https://api-docs.deepseek.com/quick_start/pricing), не строка каталога.

Каталог должен выровнять планы установки под рантайм, в котором V4 реально бежит. README плагина, который всё ещё пишет `export deepseek-chat`, — дефект документации, который можно зачесть в балл поддержки, а не другой продукт.
