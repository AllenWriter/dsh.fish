[v0.1.2-alpha.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.2-alpha.1) は 2026 年 8 月 27 日のプレビューです。changelog が長いのは、セッションの起動、プラグインの DeepSeek への名乗り、サブエージェントの起動、headless がログを出せる場所が同時に動いたからです。一覧の復唱ではなく、名前の挙がったコードに沿って読みます。

タグは `dsh-v0.1.2-alpha.1` です。`npx @deepseek-ai/dsh web` は今のプレビューパッケージに解決されます。回帰を追うときはこの tag をピンしてください。

## プラグインはリクエストに出る

公式 DeepSeek アダプタは、**有効な各プラグインのパッケージ名とバージョン**を出方向きリクエストに付けます。デプロイ側で切れます。同じ経路に、**既定オフ・明示オン**の Session ログ増分アップロードもあります。

カタログでも同じです。dsh.fish の一行は named profile へのインストール計画です。この版から、モデル提供側は実際に載ったパッケージを見られます。公開した bundle 名が、公式アダプタ使用時にマシンを出る名前です。

プラグインは**モデル設定ページに提供元ログインコントロールを登録**できます。汎用設定カードではなく、OAuth や token ログインを内蔵提供元の隣に置くためのものです。

## 起動は Profile。Python も ACP も

Python SDK や ACP から入っても、アプリは `dsh` Profile 経由で起動します。Python SDK runtime に **Windows x64** 配布が加わりました。

ACP（Agent Client Protocol）は半実装ではなくなりました。セッション制御、モデル設定、MCP、権限、キャンセルが揃ったと書かれています。欠けていた制御で止まっていたなら、この版で測り直してください。preview のまま、安定保証はありません。

## サブエージェントは自分のモデルを選べる

関連する二点です。

- 親タスクの既存認可の範囲内で、Agent はサブエージェントの提供元、モデル、推論の強さを選べます。
- サブエージェント起動時に提供元、モデル、推論の強さ、**最大出力長**を指定できます。
- Claude Code と Codex のサブエージェントは**設定されたモデル**を使い、親セッションを既定では継承しません。

第一は方針です。サブエージェントは親のモデル枠の複製ではありません。後の二つは profile で固定する方法です。Claude Code や Codex を bundle として hub profile に入れるなら、それらの子プロセスがどのモデルで走るかも書くべきです。

## ツリーから消えたもの

**ApiProxy は削除されました。** changelog は `@Remote` ゲートウェイへの移行完了と書きます。古い呼び出し経路を import するコードは載りません。

**Code Mode は PTC mode に改名。** 既存セッション記録は読めます。スクリーンショットに “Code mode” とある英語プリセットは古いです。ランタイム名は PTC です。

**公開 WebFetch は既定オン**で、SSRF 防護付き、公開 URL は毎回承認しません。以前の「毎回聞く」の逆です。その承認をゲートにしていた profile では、公開 URL に対してゲートはもうありません。

**ネットワーク経由で Web UI に触るとき、起動リンクはワンタイム token 必須。** ローカル loopback の `dsh web` は変わりません。ネットにバインドしたリスナはリンク自体で認証します。

Headless は進捗を **stderr** に出します。**stdout は最終結果だけ。** stdout からツール軌跡を grep するスクリプトは、このラウンドが終わるまで何も見ません。

## セッション UI と保存

セッション流は完了した各回答の前に過程と System prompt を折り、回答後に正確な token 使用量を開け、本文幅をドラッグできます。これは UI です。大きな履歴で重要なのは保存です。セッション記録はディスクを節約し、切れたログ末尾は自動修復され、影響を受けたセッションを警告します。

macOS/Linux の永続 PowerShell は早すぎる起動をしません。Linux の永続 Bash はパイプ途中で空出力を返しません。Bash が大量の子プロセスを起こしても macOS ホストは固まりません。Profile 設定の Agent Preset ディレクトリは起動時に消えません。読めない preset は切り替え前に印が付きます。

## 安全の注記

この tag は Safety Notice を更新しています。DeepSeek Harness は**まだセキュリティ監査を受けていません**。サンドボックス、承認、権限制御は**隔離を保証しません**。公式文であり、フォーラムの噂ではありません。`danger-full-access` はこれまでどおり扱ってください。新しい WebFetch 既定を、サンドボックスが厳しくなったと読まないでください。なっていません。

## このカタログの扱い

dsh.fish のインストール計画は、今も `$DSH_HOME` 下の named profile だけを書きます。Session ログアップロードは開きません。ApiProxy へのフォールバックも発明しません。まだ ApiProxy を書くプラグインは、この tag より古いツリー向けです。

採点モデルは変わっていません。変わったのは点が記述するランタイムです。README が Code Mode のまま、ApiProxy 断片を貼るのは、v0.1.2-alpha.1 に対する文書欠陥であり、別製品ではありません。
