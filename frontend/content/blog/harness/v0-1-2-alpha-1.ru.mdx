## Плагины попадают в запрос

Официальный адаптер DeepSeek добавляет к исходящим запросам **имя и версию каждого включённого плагина**. На стороне деплоя это можно выключить. На том же пути есть **выключенная по умолчанию, явно включаемая** инкрементальная выгрузка Session-лога.

Для каталога это тоже верно. Строка на dsh.fish — план установки в named profile. После этой версии провайдер модели видит, какие из этих пакетов реально загружены. Имя опубликованного bundle — то имя, которое при использовании официального адаптера покидает машину.

Плагины могут **регистрировать элементы входа провайдера на странице настроек модели**. Это не общая карточка настроек, а место для OAuth или token-логина рядом со встроенными провайдерами.

## Старт — это Profile, включая Python и ACP

Даже вход через Python SDK или ACP поднимает приложение через `dsh` Profile. В runtime Python SDK добавлен дистрибутив **Windows x64**.

ACP (Agent Client Protocol) больше не полуреализация. Управление сессией, настройки модели, MCP, права и отмена перечислены как закрытые пробелы. Если раньше упирались в отсутствующий контроль — перемерьте на этой версии. Это всё ещё preview, обещания стабильности нет.

## Субагент может выбрать свою модель

Две связанные вещи:

- В пределах уже выданных родителю полномочий Agent может выбрать провайдера, модель и силу рассуждения для субагента.
- При старте субагента можно задать провайдера, модель, силу рассуждения и **максимальную длину вывода**.
- Субагенты Claude Code и Codex используют **настроенную модель**, а не наследуют родительскую сессию по умолчанию.

Первое — политика: субагент не клон слота модели родителя. Остальное — как зафиксировать это в profile. Кто ставит Claude Code или Codex как bundle в hub-профиль, должен ещё указать, на какой модели бегут эти дочерние процессы.

## Что убрали из дерева

**ApiProxy удалён.** Changelog пишет, что миграция на шлюз `@Remote` завершена. Код, который всё ещё импортирует старый путь вызова, не загрузится.

**Code Mode переименован в PTC mode.** Старые записи сессий читаются. Английские пресеты со скриншотом «Code mode» устарели; имя в рантайме — PTC.

**Публичный WebFetch включён по умолчанию**, с защитой от SSRF; публичные запросы больше не требуют одобрения каждый раз. Это обратное прежнему «спрашивать всегда». Если profile держал то одобрение как затвор, для публичных URL его уже нет.

**При доступе к Web UI по сети ссылка запуска должна нести одноразовый токен.** Локальный `dsh web` на loopback не меняется; слушатель, привязанный к сети, аутентифицируется самой ссылкой.

Headless пишет прогресс в **stderr**. **stdout — только итоговый результат.** Скрипты, которые grep’или трассу инструментов из stdout, до конца раунда ничего не увидят.

## UI сессии и хранение

Поток сессии сворачивает ход рассуждения и System prompt перед каждым завершённым ответом, после ответа можно раскрыть точный расход токенов, ширину текста можно тянуть. Это UI. Для большой истории важнее хранение: записи сессий экономят диск; обрезанный хвост лога чинится сам, затронутые сессии предупреждаются.

На macOS/Linux постоянный PowerShell больше не стартует слишком рано. На Linux постоянный Bash больше не возвращает пустой вывод посреди пайпа. Хост macOS не зависает, когда Bash поднимает много дочерних процессов. Каталог Agent Preset из конфигурации Profile не теряется при старте; непреодолимый preset помечается до переключения.

## Замечание о безопасности

Этот тег обновляет Safety Notice: DeepSeek Harness **ещё не проходил аудит безопасности**. Песочница, одобрения и контроль прав **не гарантируют изоляцию**. Это официальный текст, не форумный слух. Продолжайте относиться к `danger-full-access` так, как всегда. Не читайте новый дефолт WebFetch как ужесточение песочницы. Его нет.

## Как этот каталог к этому относится

Планы установки dsh.fish по-прежнему пишут только named profile под `$DSH_HOME`. Они не включают выгрузку Session-лога и не изобретают откат на ApiProxy. Плагины, чьи README всё ещё описывают ApiProxy, смотрят на дерево старше этого тега.

Модель оценки не изменилась. Изменился рантайм, который оценка описывает. README, который всё ещё пишет Code Mode и клеит фрагмент ApiProxy, — дефект документации относительно v0.1.2-alpha.1, а не другой продукт.
