I used to keep raw footage, transcripts, other people's reference shows, my own scripts, and utility scripts in one root folder. Two weeks later I could not tell which file was meant to ship and which was only fuel. The more folders I had, the more every decision became "what is this directory for." That is managing tools, not making shows.

I collapsed it to two rules. New things go into Inbox. Finished things leave from the show folder. The transcription factory, the persona docs, the voice-clone pipeline stay backstage. Not because they do not matter. Because I should not open them every day.

The easy mistake when you are starting a channel is to treat the factory tour as the product. Listeners do not need to know who transcribes and who rewrites. They hear one episode. Internally it should work the same way. As the owner I only watch the inlet and the outlet. If the inlet is messy, even clever digital staff are just sorting trash. If the outlet is unclear, finishing a task is the same as not doing it.

This is not an architecture principle. It is admitting I cannot watch everything. If a choice can be removed from the desk, remove it.
