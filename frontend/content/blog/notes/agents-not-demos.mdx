Agent teams on DeepSeek Harness are usually asked to write code. I run a content factory with them: download, transcribe, rewrite, layout, split across different people. The hard part is not whether the model can write Chinese. The hard part is the handoff. Where the transcript lives, where the style card lives, whether a finished draft counts as published, where the audio actually goes. If those are fuzzy, a multi-agent setup only copies one person's oral mess into several people's oral mess.

On dsh.fish people ship plugins. Plugins add search, vision, sidebars, cost meters. My bottleneck is not one missing plugin. It is that after installing many, I still do not reliably produce one episode I can take. Capability is a means. The show is the delivery.

So what I ask of agents is narrow. Do not help me make the factory look more like a factory. Help me run the shortest path, and have it still be there next time. A demo can look good. A repeatable outlet is the only work log that counts.
