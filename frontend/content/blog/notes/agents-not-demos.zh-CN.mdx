DeepSeek Harness 上的 agent 团队，常见用法是写代码。我拿它跑内容工厂：下载、转写、改稿、排版，分给不同的人。困难不在模型会不会写中文。困难在交接。文字稿从哪来，风格卡放哪，成稿算不算发布，音频又出到哪。这些不写清，多智能体只是把一个人口头上的混乱，复制成好几个人口头上的混乱。

dsh.fish 上大家在发插件。插件能装很多能力：搜索、看图、侧边栏、成本统计。我自己的卡点不是少一个插件，是装了很多之后，还没有稳定地做出一期能拿走的东西。能力是手段。节目才是交付。

所以我现在对 agent 的要求很窄。不要帮我把工厂建得更像工厂。帮我把最短的那条路跑通，并且下次还在。演示很好看。能重复的出口，才算工作记录。
