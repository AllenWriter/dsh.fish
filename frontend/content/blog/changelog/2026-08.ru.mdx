Это первый changelog на сайте. Только то, что реально вышло к 29 августа 2026, не дорожная карта. Незакоммиченная работа не перечисляется.

## Продуктовые гайды ушли с одной страницы

`/docs` больше не одна React-страница с вкладками kind. Это секция Fumadocs: MDX компилируется на сборке, шесть языков, боковая колонка внутри основной, таблицы оценки вызывают `GET /api/v1/scoring`, а не вклеивают веса в текст. Гайды покрывают quickstart, понятия, каждый формат публикации, CLI, плагин hub, подачу, оценку и REST API.

Поиск по этому дереву — `/docs/search`, не `/api/search`: `/api/*` это Hono. Агент может взять любой гайд как markdown (`/docs/cli.md` или `Accept: text/markdown`). `/docs/llms.txt` генерируется из того же дерева страниц.

## Плагин hub — пакет npm

`@dsh-fish/hub` публикуется в npm и грузится как плагин Cordis внутри сессии. Ищет каталог, ставит с карточки обзора, открывает README, использует те же планы установки, что сайт. Вход с устройства починен: после Authorize в браузере токен, который плагин опрашивает, действительно обменивается.

Настройки регистрируются через клиент настроек плагинов harness. Публикация закреплена на trusted publishing npm 11.

## Таксономия каталога намеренно сжалась

`mcp-server` и `hook-bridge` больше не kind. Эти URL 301 на `/browse`. Старые гайды публикации 301 на `/docs/plugins`. Оставшиеся четыре — то, что harness реально грузит: bundle, skill, agent preset, profile.

Категории выровнены с [awesome-dsh-plugin.com](https://awesome-dsh-plugin.com). Тематические посадки (`/for/...`) покрывают короткий список намерений и остаются `noindex`, пока строк меньше трёх.

## Поверхность для агентов

`/llms.txt` у origin, `/docs/llms.txt` для гайдов, `/docs/llms-full.txt` как склейка. 404 при `Accept: text/markdown` отдаёт короткую карту восстановления, не оболочку приложения. OpenAPI и `.well-known/api-catalog` остаются машинными дверями в JSON API.

Заголовки плагинов в поиске несут summary. Переводы README держат предыдущее завершённое тело, пока замена не закончится, чтобы локаль не мигала пустой, пока крутится задача.
