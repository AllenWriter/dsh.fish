这是本站第一篇 changelog。它只写到 2026 年 8 月 29 日已经上线的内容，不是路线图。未提交的工作不列。

![目录从共享来源向人类界面、安装客户端、Web 与 agent 界面提供内容。](/blog/diagrams/hub-surfaces.svg)

## 产品文档离开了单页

`/docs` 不再是带 kind 标签页的一个 React 页面。它是 Fumadocs 分区：构建期编译 MDX、六种语言、栏内边栏、评分表走 `GET /api/v1/scoring` 而不是把权重粘在文里。指南覆盖 quickstart、概念、每种发布格式、CLI、hub 插件、提交、评分和 REST API。

这棵树的搜索在 `/docs/search`，不在 `/api/search`——`/api/*` 是 Hono。Agent 可以把任意指南当 markdown 拉（`/docs/cli.md`，或 `Accept: text/markdown`）。`/docs/llms.txt` 从同一棵页面树生成。

## hub 插件是 npm 包

`@dsh-fish/hub` 发布到 npm，作为 Cordis 插件在会话里加载。它搜索目录、从浏览卡片安装、打开 README，用的安装计划和网站上看到的是同一份。设备登录已修好：浏览器里点授权后，插件轮询的 token 真的会被兑换。

设置通过 harness 的插件设置客户端注册。发布钉在 npm 11 的 trusted publishing 上。

## 目录分类有意变小

`mcp-server` 和 `hook-bridge` 不再是 kind。那些 URL 301 到 `/browse`。旧的发布指南 301 到 `/docs/plugins`。剩下四种是 harness 真正加载的：bundle、skill、agent preset、profile。

分类与 [awesome-dsh-plugin.com](https://awesome-dsh-plugin.com) 对齐。主题落地页（`/for/...`）只覆盖一小份意图列表，少于三行时保持 `noindex`。

## 面向 agent 的表面

源站 `/llms.txt`，指南 `/docs/llms.txt`，拼接版 `/docs/llms-full.txt`。`Accept: text/markdown` 的 404 返回短恢复地图，而不是应用壳。OpenAPI 和 `.well-known/api-catalog` 仍是进 JSON API 的机器入口。

搜索结果里的插件标题带上 summary。README 翻译在替换完成前保留上一份已完成正文，避免任务跑着时某个语言闪成空白。

## 为什么共享来源重要

看得见的成果是文档树、博客和可安装插件，底下那条工程约束更有价值：任何表面都不私存一份目录事实。网站、CLI 和 hub 插件解析同一份安装计划；文档搜索、Markdown 内容协商、`llms.txt`、Atom 和 sitemap 则从各自的 MDX 树生成。

这消除了一个常见故障：页面说一套，agent 端点说另一套。代价是写作必须更严格。源树里缺少路由或 locale 文件时，不能在组件里塞一段文字糊过去；一致性检查和链接检查会直接失败。

## 可以怎么试

按工作选择对应表面：

- 想了解发布契约，浏览 `/docs`。
- agent 需要同一份材料，获取 `/docs/llms.txt` 或 `.md` 路由。
- 不打开网站也想拿到安装计划，运行 `npx @dsh-fish/cli`。
- 希望计划留在 Harness 会话里，加载 `@dsh-fish/hub`。

限制是有意的：本次发布没有博客搜索，`/api/search` 仍然是目录搜索，不是第二套内容索引。
