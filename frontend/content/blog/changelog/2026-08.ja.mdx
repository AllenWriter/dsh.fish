本サイト最初の changelog です。2026 年 8 月 29 日までに実際に載ったものだけを書きます。ロードマップではありません。未コミットの作業は列挙しません。

![共有ソースから、人向け、インストールクライアント、Web、agent 向けの各面へカタログを配信する流れ。](/blog/diagrams/hub-surfaces.svg)

## 製品ドキュメントは単一ページを出た

`/docs` は kind タブ付きの一つの React ページではありません。Fumadocs 区画です。ビルド時に MDX をコンパイルし、六言語、欄内サイドバー、採点表は重みを本文に貼らず `GET /api/v1/scoring` を呼びます。ガイドは quickstart、概念、各公開形式、CLI、hub プラグイン、提出、採点、REST API を覆います。

この木の検索は `/docs/search` であり `/api/search` ではありません。`/api/*` は Hono です。エージェントは任意のガイドを markdown として取れます（`/docs/cli.md`、または `Accept: text/markdown`）。`/docs/llms.txt` は同じページ木から生成されます。

## hub プラグインは npm パッケージ

`@dsh-fish/hub` は npm に公開され、Cordis プラグインとしてセッション内で載ります。カタログを検索し、閲覧カードからインストールし、README を開き、サイトと同じインストール計画を使います。デバイスログインは直しました。ブラウザで認可すると、プラグインがポーリングしている token が本当に兌換されます。

設定は harness のプラグイン設定クライアント経由で登録します。公開は npm 11 の trusted publishing にピンしています。

## カタログ分類は意図して小さくなった

`mcp-server` と `hook-bridge` は kind ではありません。それらの URL は `/browse` へ 301 します。古い公開ガイドは `/docs/plugins` へ 301 します。残る四種は harness が実際に載せるものです。bundle、skill、agent preset、profile。

分類は [awesome-dsh-plugin.com](https://awesome-dsh-plugin.com) に揃えました。トピック落地（`/for/...`）は短い意図リストだけを覆い、行が三未満なら `noindex` のままです。

## エージェント向けの面

オリジンの `/llms.txt`、ガイドの `/docs/llms.txt`、連結版 `/docs/llms-full.txt`。`Accept: text/markdown` の 404 は短い回復地図を返し、アプリ殻ではありません。OpenAPI と `.well-known/api-catalog` は JSON API への機械入口のままです。

検索結果のプラグインタイトルは summary を載せます。README 翻訳は置換が終わるまで前の完成本文を保ち、ジョブ実行中にロケールが空に点滅しないようにします。

## 共有ソースが重要な理由

見える成果はドキュメントツリー、ブログ、インストール可能なプラグインです。その下にある技術的な制約のほうが重要です。どの面もカタログの事実を独自に複製しません。Web サイト、CLI、hub プラグインは同じインストール計画を解決し、ドキュメント検索、Markdown ネゴシエーション、`llms.txt`、Atom、sitemap はそれぞれの MDX ツリーから生成されます。

これで、ページと agent 向けエンドポイントが違う説明をするという典型的な失敗を避けられます。その代わり執筆は厳格です。ソースツリーからルートやロケールファイルが欠けていれば、コンポーネントに文章を埋め込んで取り繕うことはできず、同等性チェックとリンクチェックが失敗します。

## 試すこと

作業に合う面を使ってください。

- 公開契約を学ぶなら `/docs` を読む。
- agent が同じ資料を必要とするなら `/docs/llms.txt` または `.md` ルートを取得する。
- サイトを開かずインストール計画を確認するなら `npx @dsh-fish/cli` を実行する。
- 計画を Harness セッション内に保つなら `@dsh-fish/hub` をロードする。

制約は意図的です。このリリースにブログ検索は含まれず、`/api/search` は二つ目のコンテンツ索引ではなく、カタログ検索のままです。
