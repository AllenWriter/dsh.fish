這是本站第一篇 changelog。它只寫到 2026 年 8 月 29 日已經上線的內容，不是路線圖。未提交的工作不列。

![目錄從共享來源向人類介面、安裝客戶端、Web 與 agent 介面提供內容。](/blog/diagrams/hub-surfaces.svg)

## 產品文件離開了單頁

`/docs` 不再是帶 kind 標籤頁的一個 React 頁面。它是 Fumadocs 分區：建置期編譯 MDX、六種語言、欄內邊欄、評分表走 `GET /api/v1/scoring` 而不是把權重黏在文裡。指南覆蓋 quickstart、概念、每種發布格式、CLI、hub 外掛、提交、評分和 REST API。

這棵樹的搜尋在 `/docs/search`，不在 `/api/search`——`/api/*` 是 Hono。Agent 可以把任意指南當 markdown 拉（`/docs/cli.md`，或 `Accept: text/markdown`）。`/docs/llms.txt` 從同一棵頁面樹生成。

## hub 外掛是 npm 套件

`@dsh-fish/hub` 發布到 npm，作為 Cordis 外掛在工作階段裡載入。它搜尋目錄、從瀏覽卡片安裝、打開 README，用的安裝計畫和網站上看到的是同一份。裝置登入已修好：瀏覽器裡點授權後，外掛輪詢的 token 真的會被兌換。

設定透過 harness 的外掛設定用戶端註冊。發布釘在 npm 11 的 trusted publishing 上。

## 目錄分類有意變小

`mcp-server` 和 `hook-bridge` 不再是 kind。那些 URL 301 到 `/browse`。舊的發布指南 301 到 `/docs/plugins`。剩下四種是 harness 真正載入的：bundle、skill、agent preset、profile。

分類與 [awesome-dsh-plugin.com](https://awesome-dsh-plugin.com) 對齊。主題落地頁（`/for/...`）只覆蓋一小份意圖列表，少於三列時保持 `noindex`。

## 面向 agent 的表面

源站 `/llms.txt`，指南 `/docs/llms.txt`，拼接版 `/docs/llms-full.txt`。`Accept: text/markdown` 的 404 回傳短恢復地圖，而不是應用殼。OpenAPI 和 `.well-known/api-catalog` 仍是進 JSON API 的機器入口。

搜尋結果裡的外掛標題帶上 summary。README 翻譯在替換完成前保留上一份已完成正文，避免任務跑著時某個語言閃成空白。

## 為什麼共享來源重要

看得見的成果是文件樹、部落格與可安裝外掛，底下那條工程約束更有價值：任何表面都不私存一份目錄事實。網站、CLI 與 hub 外掛解析同一份安裝計畫；文件搜尋、Markdown 內容協商、`llms.txt`、Atom 與 sitemap 則從各自的 MDX 樹產生。

這消除了一個常見故障：頁面說一套，agent 端點說另一套。代價是寫作必須更嚴格。來源樹裡缺少路由或 locale 檔案時，不能在元件裡塞一段文字帶過；一致性檢查與連結檢查會直接失敗。

## 可以怎麼試

依工作選擇對應表面：

- 想了解發布契約，瀏覽 `/docs`。
- agent 需要同一份材料，取得 `/docs/llms.txt` 或 `.md` 路由。
- 不開網站也想拿到安裝計畫，執行 `npx @dsh-fish/cli`。
- 希望計畫留在 Harness 工作階段裡，載入 `@dsh-fish/hub`。

限制是刻意的：本次發布沒有部落格搜尋，`/api/search` 仍然是目錄搜尋，不是第二套內容索引。

它不是 DeepSeek Harness 的發版。Harness 版本在 [Harness 版本](/blog/harness)。它也不是每一筆 commit。裝置授權競態、sitemap 查詢上限、ads.txt 都在 git 裡；不是有人來這裡要看的東西。
